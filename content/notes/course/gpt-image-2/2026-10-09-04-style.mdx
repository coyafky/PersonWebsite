##  第四节：视觉风格（Style）——从写实摄影到动漫、电影与 3D 渲染

GPT Image 生图从 0 到 1 · 第 04 课 · 视觉风格控制

在第三节，我们学习了构图（Composition），知道如何控制主体的位置、比例、视角和画面布局。

这一节，我们开始研究 AI 生图中最具创造性的部分：视觉风格（Visual Style）。

同一个少女角色，可以生成真实摄影照片、动漫角色、电影剧照、三维角色渲染，甚至水彩插画。

而我们的目标不是简单地告诉 AI“生成动漫风格”，而是学会逐层控制：

风格大类 → 风格子类 → 视觉特征 → 材质表现 → 风格约束。

### 4.1 什么是视觉风格？

视觉风格是指一张图片在表现形式上具有的共同特征，包括线条、颜色、材质、纹理、细节处理以及整体美术语言。

### 4.2 视觉风格的五层控制模型

我们可以把视觉风格描述分成五层：

L1 · 风格大类（Category）

写实 / 动漫 / 电影 / 3D / 插画



L2 · 风格子类（Substyle）

如日系赛璐璐、日系厚涂、低多边形、电影胶片



L3 · 视觉特征（Visual Language）

线条粗细、阴影层次、饱和度、细节密度



L4 · 材质与表现（Material & Rendering）

肌肤、头发、布料、反射、高光、笔触



L5 · 风格约束（Style Constraints）

保持哪些特征？排除哪些不希望出现的风格？

举个例子：

普通提示词：

> 一个动漫少女。

升级后的风格描述：

> 日系二维动漫风格，精细赛璐璐上色，轮廓线清晰，皮肤采用平滑色块，头发使用分层阴影和少量高光，整体配色柔和，禁止真实摄影皮肤纹理和明显三维塑料质感。

这就是从“风格名称”升级到“视觉表现规则”。

#### 写实摄影提示词模板

**主体：** 参考图中的蓝发少女，保持原有蓝色长发、蓝色眼睛、女仆头饰及深蓝白色服装。

**风格大类：** 写实人物摄影（Photorealism）

**风格子类：** 专业商业棚拍（Studio Portrait）

**视觉特征：** 自然肤质、真实发丝、合理的人体比例，保留细微皮肤纹理。

**风格约束：** 不采用动漫线稿，不采用明显的塑料皮肤效果，不改变原角色服装的核心设计。

**固定构图：** 3:4 竖版，人物正面半身像，居中构图，浅灰色背景，柔和均匀光线。

### 4.8 风格控制：把模糊词变成具体描述

初学者经常使用一些过于宽泛的词，例如：

“高级感”“动漫感”“电影质感”“超清晰”。

这些词可以表达审美方向，但不能替代具体的视觉指令。

| 模糊描述 | 更精确的描述                           |
| -------- | -------------------------------------- |
| 高级感   | 克制配色、充足留白、柔和反差、精细材质 |
| 动漫感   | 二维线稿、赛璐璐阴影、动漫化五官比例   |
| 电影感   | 低调布光、冷暖分级、镜头景深、胶片颗粒 |
| 3D 感    | 明确体积、材质反射、空间光照、几何厚度 |
| 手绘感   | 可见笔触、非均匀边缘、纸张肌理         |

当然，风格的表现没有唯一正确答案。选择哪种描述，取决于你希望最终图片呈现什么视觉结果。

### 本节总结

视觉风格控制的关键，不是堆砌大量风格名称，而是理解每种风格背后的视觉规律。

本节需要掌握的公式是：

视觉风格 = 风格大类 + 子类 + 视觉特征 + 材质与渲染方式 + 风格约束。

到这里，我们已经拥有了基本的风格控制能力。
