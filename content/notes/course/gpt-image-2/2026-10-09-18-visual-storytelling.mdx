## 第十八节：视觉叙事与分镜控制（Visual Storytelling & Storyboard）

GPT 生图从 0 到 1 · 第 18 课 · 连续画面、角色一致性、镜头衔接、情绪递进与图文叙事

在前十七节中，我们已经学习了如何精确控制一张图片：包括构图、风格、镜头、光影、人物动作、空间、环境以及产品展示。

但实际创作中，我们经常需要的不只是一张图。

例如：

- 用 6 张图片讲述一位少女在内蒙古草原旅行的故事。
- 用 4 张图片展示一辆汽车从驶入门店到完成轻改升级的过程。
- 用 8 张小红书图文，向车主解释为什么需要贴隐形车衣。
- 用一组连续分镜，展示一个产品从设计、制造到实际使用的过程。

这时我们面临的新问题是：

如何让多张独立生成的图片，看起来属于同一个故事、同一个世界、同一组人物？

本节将从单张图片的 Prompt Engineering 进入连续画面的 Visual Storytelling（视觉叙事） 和 Storyboard（分镜设计）。

视觉叙事

存在事件发展和前后因果

| 类型     | 主要特征                 | 示例                             |
| -------- | ------------------------ | -------------------------------- |
| 单图     | 独立表达一个画面主题     | 少女站在草原                     |
| 系列图   | 多张图片共享主题或风格   | 草原四季写真                     |
| 叙事分镜 | 多张画面按时间或逻辑发展 | 少女抵达草原、出发、探索、看日落 |

重要区别：图片风格统一，并不代表它们具有叙事关系。

只有当图片之间存在时间推进、动作变化、情绪递进、因果关系或信息论证时，才真正形成了视觉叙事。

### 18.2 视觉叙事的八大控制维度

<VisualStorytellingFramework />

这八个维度会共同决定一组图片是否能够形成连贯的故事。

### 18.3 第一部分：故事结构（Story Arc）

我们先不要急着生成图片，而是确定故事到底要讲什么。

对于入门课程，可以采用最简单的四阶段叙事：

四阶段故事结构

01

开端

Setup

谁、在哪里

02

发展

Development

发生了什么

03

转折

Turning Point

出现变化

04

结果

Resolution

最终状态

例如，我们要做一个《少女的草原之旅》系列：

| 阶段 | 画面                     | 叙事作用       |
| ---- | ------------------------ | -------------- |
| 开端 | 少女刚来到草原           | 建立人物和环境 |
| 发展 | 少女沿草原小路行走       | 展示探索过程   |
| 转折 | 她登上山丘，看见辽阔风景 | 形成视觉高潮   |
| 结果 | 黄昏时坐在草地上望向夕阳 | 形成情绪收束   |

这个故事没有复杂的戏剧冲突，但依然具有明确的时间顺序与情绪变化。

对于商业图文，四阶段结构也可以改成：

用户问题 → 原因分析 → 解决方案 → 结果与证据。

### 18.4 第二部分：角色一致性（Character Consistency）

连续分镜最容易出现的问题就是人物漂移。

例如，第一张是黑色长发，第三张变成棕发；第一张穿白色长裙，第四张衣服突然改变。

我们需要建立一个 Character Bible（角色设定档案）。

#### 角色设定卡

角色 A · 草原旅行者

Character ID: GIRL-001

成年东方女性，黑色长发，米白色长裙，自然妆容，写实人像摄影风格。

统一角色参考

| 核心身份 | 同一成年女性，主要面部特征稳定   |
| -------- | -------------------------------- |
| 发型     | 黑色长发，长度与发际线尽量一致   |
| 服装     | 米白色长裙，款式和细节一致       |
| 允许变化 | 动作、姿势、表情、镜头景别       |
| 禁止变化 | 人物身份、主要发型、服装核心设计 |

正式生图时，角色参考应该尽量来自同一张基准图或经过确认的角色参考集，而不能只是每次重复一段类似的人物描述。

#### 角色保持提示词

使用图片 A 作为本系列唯一人物身份参考。

所有分镜必须保持同一位成年女性的主要面部特征、黑色长发、米白色长裙与核心配饰。

允许人物动作、表情、镜头位置和景别根据分镜内容发生变化。

不允许人物身份漂移、发色变化、服装款式突变或凭空增加配饰。

每张画面延续同一角色设定，但不要求人物在所有分镜中保持相同姿势。

### 18.5 第三部分：场景连续性（Scene Continuity）

角色不变，还不足以保证故事连贯。

因为同一个人在每张图中出现，但背景里的山丘、建筑、道具不断变化，依然会让读者感觉故事发生在不同地点。

#### 场景连续性的四个锚点

| 锚点     | 作用             | 草原案例                 |
| -------- | ---------------- | ------------------------ |
| 地理锚点 | 固定地点特征     | 同一片起伏草原           |
| 地标锚点 | 帮助识别位置     | 远处一座独特的缓坡       |
| 道具锚点 | 维持故事关联     | 同一只旅行背包           |
| 环境锚点 | 维持真实世界状态 | 夏季草地、天气与时间变化 |

### 18.6 第四部分：镜头衔接（Shot Progression）

这是分镜设计中最核心的知识点之一。

一组图片如果全部使用相同的中景构图，虽然可能很统一，却容易显得平淡。

电影和漫画经常交替使用不同景别，控制观众对信息的感知。

### 18.7 第五部分：动作连续性（Action Continuity）

连续动作的控制比单张姿态更复杂。

例如：

一位少女先拿起马克杯，再将杯子靠近嘴边，最后放回桌面。

我们需要明确每张图对应的动作阶段。

01

拿起

右手握住杯柄

02

靠近

右手抬至嘴边

03

放下

杯子回到桌面

连续动作需要控制：

- 同一只手执行同一个动作。
- 道具不突然改变形状或位置。
- 动作阶段具有合理的先后顺序。
- 人物的身体朝向与场景位置不无故跳变。
- 相邻画面之间的动作关系能够被读者理解。

#### 动作连续性提示词

使用同一位人物、同一张桌子和同一只白色马克杯生成三张连续分镜。

分镜一：人物右手刚刚握住桌面上的杯柄。

分镜二：人物右手将杯子抬至嘴边，杯身保持自然直立。

分镜三：人物将杯子重新放在桌面原来的位置。

三张图保持人物身份、服装、桌面布局、杯子尺寸与背景一致。

人物始终使用右手操作杯子。

每张图只展示一个明确的动作阶段，不在同一张图中叠加多个时间状态。

手部和杯柄的接触自然，不出现多余手指、物体穿透或杯子形状变化。

时间变化应该影响真实环境：

| 时间变化   | 可能伴随的视觉变化                 |
| ---------- | ---------------------------------- |
| 清晨至正午 | 太阳高度变化、阴影长度变化         |
| 正午至黄昏 | 阳光角度降低、暖色光照更常见       |
| 黄昏至夜晚 | 环境亮度下降、人工照明可能变得重要 |
| 天气变化   | 云层、地面干湿与能见度发生相应变化 |

不能只改变天空颜色，却让太阳方向、地面阴影与所有物体高光完全不变。

#### 情绪递进与色彩

例如：

期待 → 好奇 → 惊喜 → 宁静

可以通过表情、身体姿态、镜头景别、环境规模和光线共同表达，而不是单独依靠不同颜色。

### 18.9 第七部分：分镜中的方向一致性（Screen Direction）

这是专业视觉叙事中一个容易被忽略的问题。

例如，人物在上一张图中向右行走，下一张图突然向左行走，观众可能以为她已经转身返回。

如果故事实际上仍在朝同一个方向前进，我们就需要维持方向一致性。

运动方向连续性示意

向右 → 向右

 方向连续

向右 → 向左

 可能造成方向混淆

这里涉及电影中的 180 度轴线原则（180-degree Rule）。

它的基本思想是：在描述人物互动或运动时，可以在空间中建立一条动作轴线，并尽量让相机停留在轴线同一侧，以保持左右方位关系稳定。

但 180 度轴线原则并非不能打破。只要通过过渡镜头、人物运动或明确的空间交代，越轴也可以成为合理的叙事选择。

对于多张 AI 生图，建议在分镜表里记录每张图片的运动方向和相机方位。

### 18.11 完整案例二：汽车轻改的视觉叙事

这次我们从人物旅行转向商业故事。

假设要制作一组新能源汽车电动踏板升级图文。

可以采用：

用户痛点 → 产品方案 → 施工过程 → 安装结果 → 使用体验 → 行动引导。

汽车产品六镜头叙事结构

1. 用户场景（Problem）

   车主准备上下较高车身的 SUV，展示使用场景，不夸张制造安全风险。

2. 展示产品（Product）

   电动踏板实物特写，重点呈现面板与防滑结构。

3. 适配确认（Fitment）

   展示车型与产品适配信息，使用经过确认的数据。

4. 安装施工（Installation）

   展示真实施工流程；若素材为生成图，应明确标注示意。

5. 使用效果（Result）

   踏板伸出，车主上下车，展示实际使用价值。

6. 品牌收束（CTA）

   车型、产品与品牌信息，以精确排版形式承接咨询。

这一套图文与普通电商主图的差别在于：

单张商品图展示“产品是什么”。

而连续叙事要说明“用户为什么需要它、它如何解决问题，以及用户如何判断它是否适合自己”。

对于真实施工和产品性能，优先使用可核验的现场照片与资料；AI 生成图更适合承担场景示意、视觉表达和概念展示。

### 18.12 第八部分：博客和小红书图文如何转换为分镜？

这一部分是视觉叙事非常实用的应用。

例如，你之前研究过“窗膜的前世今生”主题，可以把一篇长文章拆分为视觉叙事。

| 页码 | 内容任务   | 建议画面                   |
| ---- | ---------- | -------------------------- |
| 01   | 提出问题   | 汽车暴晒、车内热感的场景   |
| 02   | 历史背景   | 早期汽车玻璃与遮阳方式     |
| 03   | 技术演进   | 不同窗膜技术的历史阶段     |
| 04   | 工作原理   | 太阳辐射与玻璃膜层示意     |
| 05   | 用户价值   | 隔热、可见光透过和使用体验 |
| 06   | 选择方法   | 关键参数比较信息图         |
| 07   | 施工流程   | 清洁、贴膜、赶水、收边     |
| 08   | 总结与行动 | 常见误区、适配咨询入口     |

这类知识型图文的叙事不一定依赖人物连续动作，而是通过信息层次与论证顺序推进。

可以使用：

问题 → 背景 → 原理 → 比较 → 实例 → 结论。

这也是为什么视觉叙事不能简单理解为电影分镜。

### 18.13 分镜一致性的三层控制模型

为了避免连续生成时出现人物和场景漂移，我们建议把整个项目的控制要求分成三层。

Global Constants · 全局常量

角色身份、服装、主要场景、画风、画幅、项目视觉规范

Scene Variables · 镜头变量

景别、相机方位、人物动作、道具状态、时间、情绪

Continuity Constraints · 连续性约束

前后镜头之间的动作、位置、方向、道具与时间必须衔接

例如，六张草原分镜可以共享：

```
CHARACTER_ID = GIRL-001
OUTFIT = Ivory long dress
LOCATION = Inner Mongolia grassland
STYLE = Photorealistic cinematic photography
ASPECT_RATIO = 16:9
```

然后每张图具有自己的参数：

```
SHOT_01:
  ShotSize = Wide
  Action = Arriving
  Time = Morning
  Mood = Anticipation

SHOT_02:
  ShotSize = Full
  Action = Walking
  Time = Morning
  Mood = Curiosity
```

这样就把第八节的常量、变量管理引入到连续叙事中。

- 道具状态正确
- 镜头完成叙事任务
- 全部图片风格协调

### 18.17 本节总结

视觉叙事的核心公式：

连续视觉叙事 = 故事结构 + 角色一致性 + 场景连续性 + 镜头衔接 + 动作逻辑 + 情绪递进 + 时间变化 + 视觉规范。

通过第十八节，我们应该掌握三个重要原则。

第一，分镜先于生图。 在生成之前，先确定每张图片要传达什么信息，以及它与上一张图有什么关系。

第二，一致性不代表所有镜头都必须相同。 人物和关键场景要稳定，但镜头、动作、情绪和时间应该根据故事发展产生变化。

第三，连续图像要作为整体进行验收。 单张图片看起来很优秀，也可能因为与前后镜头冲突而不适合整组故事。
