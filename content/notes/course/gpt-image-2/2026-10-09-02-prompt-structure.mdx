## 第二节：GPT Image 2 生图提示词的基础结构（Prompt Structure）

在上一节，我们学习了图片比例（Aspect Ratio）。这一节，我们开始研究 AI 生图中更重要的问题：

如何把脑海中的画面，转换成 AI 能够理解并执行的提示词？

你提到的图片比例、九宫格、四宫格、对称构图、动漫风格、写实风格、电影感、光影、镜头位置等，其实属于不同的视觉控制维度。

为了建立系统的学习框架，我们先不深入每一种风格或构图方法，而是搭建一套可以不断扩展的 六模块提示词基础模板。

### 2.1 提示词的六大核心模块

PROMPT STRUCTURE · 六模块架构

01 · 画面目标与主体（Subject）

生成什么？用于什么地方？

02 · Canvas & Composition

画布与构图

比例、主体位置、九宫格

03 · Style & Material

风格与材质

写实、动漫、电影感

04 · Camera & Perspective

镜头与视角

景别、角度、焦距

05 · Lighting & Color

光影与色彩

光源、色调、氛围

06 · 约束条件（Constraints）

哪些必须保持？哪些禁止出现？哪些必须准确？

这六个模块并不是模型内部固定的参数，而是我们为了学习和复用而设计的提示词工程框架。

| 模块         | 核心问题               | 典型描述                       |
| ------------ | ---------------------- | ------------------------------ |
| ① 主体与目标 | 画面里是什么？         | 新能源汽车、轮毂、电动踏板     |
| ② 画布与构图 | 如何组织画面？         | 1:1、对称、三分法、四宫格      |
| ③ 风格与材质 | 画面看起来像什么？     | 商业写实、日系动漫、3D 渲染    |
| ④ 镜头与视角 | 从哪里观察主体？       | 俯视、平视、特写、三分之四视角 |
| ⑤ 光影与色彩 | 画面的视觉氛围是什么？ | 柔光、侧逆光、冷蓝色调         |
| ⑥ 约束条件   | 什么必须满足？         | 不改变产品结构、禁止多余文字   |

要特别区分两个层级：

- 基础结构：解决提示词应该包含哪些信息。
- 精确控制：解决每个模块应该如何描述，才能减少生成结果与预期的偏差。

后续的九宫格构图、电影级光影、镜头焦距、动漫风格细分类，都属于第二层的深入学习。

### 2.2 从一句话到完整提示词

假设我们的目标是生成一张新能源汽车商业图片。

Level 1 · 基础描述

一台蓝色新能源汽车。

AI 需要自行决定画面比例、环境、车型姿态、光线和摄影风格，结果的不确定性较高。

Level 2 · 增加视觉控制

一台蓝色新能源汽车，1:1 正方形画面，三分之四侧前视角，车辆居中，白色摄影棚背景，写实商业摄影风格，柔和顶光。

增加比例、构图、镜头、风格和光影，让生成方向更加明确。

Level 3 · 增加约束条件

一台蓝色新能源汽车，1:1 正方形，三分之四侧前视角，白色摄影棚背景，写实汽车商业摄影，柔和顶光。

严格要求：完整展示车身，车辆占画面宽度约 80%，四周预留安全边距。禁止裁切车辆、禁止额外车辆、禁止水印或无关文字。

将模糊的视觉目标转变为可检查的要求。约束可以提高可控性，但并不保证模型每次都严格执行。

### 2.3 第六模块：约束条件为什么特别重要？

我们可以把约束分成四种。

| 约束类型 | 解决的问题         | 提示词示例               |
| -------- | ------------------ | ------------------------ |
| 正向约束 | 必须出现什么       | 车辆必须完整可见         |
| 负向约束 | 禁止出现什么       | 不出现其他汽车           |
| 保持约束 | 什么不能改变       | 参考图轮毂辐条结构不变   |
| 精确约束 | 哪些细节有具体标准 | 四宫格、每格展示一款产品 |

还有一个关键概念：约束优先级。

例如，你上传了一张轮毂参考图，希望生成电商主图，要求可以划分为：

P0 · 不可违反

主体真实性

保留轮毂辐条数量、形状、中心盖和产品配色。

P1 · 优先满足

画面结构

1:1 正方形、轮毂居中、完整展示外圈。

P2 · 可调整

艺术表现

背景灰度、反光强弱、阴影柔和程度。

这意味着，当视觉美化与产品真实性发生冲突时，应优先保留产品真实性。

不过，P0/P1/P2 是我们给任务建立的优先级标记，不是 GPT Image 2 官方提供的强制执行机制。涉及精准品牌 Logo、实物规格或细节不可改变的商品图，仍然需要人工检查；像素级保持最好使用原始素材与确定性图像编辑流程，而非完全依赖重生成。

### 2.4 通用六模块提示词模板

这是我们整套课程后续会持续使用的基础模板。

## AI 图片生成提示词模板 V1.0

### 01. 画面目标与主体（Subject）

- 图片用途：[电商主图 / 小红书 / 海报 / 网站 Banner]
- 核心主体：[具体描述]
- 场景背景：[具体描述]
- 关键展示内容：[主体的哪些特征最重要]

### 02. 画布与构图（Canvas & Composition）

- 图片比例：[1:1 / 3:4 / 9:16 / 16:9]
- 构图方式：[居中 / 对称 / 三分法 / 四宫格 / 九宫格]
- 主体位置：[左 / 中 / 右 / 具体区域]
- 主体占比：[如画面宽度的 75%]
- 留白区域：[顶部 / 左侧 / 底部]

### 03. 视觉风格与材质（Style & Material）

- 主风格：[商业写实 / 电影 / 动漫 / 3D]
- 子风格：[具体视觉参考]
- 材质表现：[金属 / 玻璃 / 漆面 / 织物]
- 细节程度：[质感、纹理、清晰度要求]

### 04. 镜头与视角（Camera & Perspective）

- 镜头角度：[正视 / 俯视 / 仰视 / 45度]
- 景别：[特写 / 中景 / 全景]
- 透视效果：[自然透视 / 广角 / 长焦压缩感]
- 景深：[背景清晰 / 浅景深]

### 05. 光影与色彩（Lighting & Color）

- 光线类型：[自然光 / 棚拍光 / 电影光]
- 光线方向：[正面 / 侧面 / 逆光]
- 光线质感：[柔和 / 硬朗 / 高反差]
- 主色调：[颜色及配色比例]
- 整体氛围：[科技 / 温暖 / 高级 / 活泼]

### 06. 约束条件（Constraints）

- P0 必须保持：[产品结构、品牌标识等]
- P1 必须满足：[构图、比例、主体数量等]
- P2 可调整：[背景、装饰、光影细节]
- 禁止内容：[额外主体、乱码、水印等]
- 输出检查：[列出验收标准]

### 2.5 后续的精确控制知识树

你之前提到的九宫格、对称构图、电影风格、动漫风格，都可以逐渐扩展成独立的知识模块。

AI 生图视觉控制体系

01

构图控制

居中、对称、三分法、四宫格、九宫格、黄金分割、留白

02

风格控制

摄影写实、动漫、插画、电影、3D、平面设计，以及各自子风格

03

镜头控制

正视、侧视、俯视、仰视、焦距、景别、景深

04

光影控制

主光、辅光、轮廓光、硬光、柔光、色温

05

材质控制

金属、玻璃、塑料、碳纤维、车漆、织物

06

精度控制

参考图一致性、文字准确性、主体数量、局部编辑

### 2.6 本节总结

本节只需要真正掌握一个公式：

生图提示词 = 主体目标 + 画布构图 + 视觉风格 + 镜头视角 + 光影色彩 + 约束条件。

并不是每次生图都必须写满六个模块。简单创作可以简写，商业图片需要更明确的验收标准，而要求保持产品真实性的任务应突出参考图和保持约束。

下一节建议正式进入 第三节：构图控制（Composition），从居中、对称、三分法，逐步学习到四宫格、九宫格和复杂多主体布局。届时我们可以给每一种构图配上视觉示意图、可复制提示词和实际生成案例，让博客成为一套可查阅的生图知识手册。



可以，而且**非常有必要**。

对于这篇「从 0 到 1 学习 GPT 生图」博客来说，最好不要只有文字说明，而是做一组**教学型配图**。
这样读者会更容易理解“同一个主体，在不同提示词控制下，画面到底会怎么变”。

我建议把博客配图分成两类：

### 一、博客最需要的两类图片

#### A. 概念示意图

用来解释知识点本身，比如：

1. **图片比例对比图**
   同一主体，分别展示 1:1、3:4、9:16、16:9
2. **构图对比图**
   同一主体，展示居中构图、三分法、对称构图、四宫格
3. **风格对比图**
   同一主体，展示写实风、电影感、动漫风、3D 渲染风
4. **镜头视角对比图**
   同一主体，展示正视、俯视、仰视、三分之四侧前视角
5. **光影对比图**
   同一主体，展示柔光、硬光、逆光、棚拍光
6. **约束条件对比图**
   展示“无约束生成”和“有约束生成”的差别

------

#### B. 实战案例图

用来说明“提示词从简单到完整”的变化，比如：

1. **一句话提示词生成结果**
2. **加入比例和构图后的结果**
3. **加入风格和镜头后的结果**
4. **加入约束条件后的结果**

这类图非常适合写成“逐步升级案例”。

### 三、最推荐的制作思路

为了让整篇博客更专业，建议你采用一个原则：

**所有示例图尽量使用“同一个主体”反复演示。**

比如统一用：

- 一台蓝色新能源 SUV
- 或一只白色马克杯
- 或一个轮毂产品

这样读者能更清晰地看出：

- 变化的是“提示词控制维度”
- 不是“主体内容本身”

如果每张图主体都不同，教学效果会弱很多。

------

### 四、我建议你这篇博客的统一示例主体

结合你平时的业务，我更建议用：

**统一主体：一台蓝色新能源 SUV / 新能源汽车**

原因：

1. 和你后续汽车后市场内容一致
2. 适合讲比例、构图、风格、镜头、光影
3. 既能做商业感，又能做教学案例
4. 后面如果扩展到商品主图、海报、Banner，也能继续沿用
