## 第二十二节：角色与产品一致性进阶（Consistency Mastery）

GPT 生图从 0 到 1 · 第 22 课 · 角色设定图、三视图、多参考图、跨场景复用与主体漂移控制

前二十一节，我们已经学习了从单张图片生成到局部编辑、商业摄影、视觉叙事和图片质量控制的完整知识体系。

在第八节《参考图与一致性控制》中，我们学习了如何利用参考图片保护人物、产品结构和品牌信息。

而第二十二节要解决一个更复杂的问题：

如何让同一个人物或产品，在几十张不同视角、不同场景、不同动作的图片中，依然保持高度一致？

例如：

- 一位蓝发少女，分别出现在草原、海边、咖啡馆和摄影棚，仍然是同一个角色。
- 同一款锻造轮毂，需要正面、侧面、背面、微距和安装效果图，辐条及产品设计不能改变。
- 一张动漫角色原图，需要扩展成角色三视图、表情集、动作集。
- 需要为同一车型生成四季场景图，但车身颜色、车型、灯组与轮毂都保持一致。
- 一个品牌连续制作 100 张商品主图，所有产品图遵守同样的品牌设计规范。

这一节，我们要把“参考图辅助生成”升级为可管理、可测试、可回退的主体一致性体系。

### 22.1 一致性并不是只有一种

在图生图工作中，我们要先明确：究竟什么东西需要保持不变？

CONSISTENCY CONTROL FRAMEWORK

01 · Identity

身份一致性

是否还是同一位人物或角色

02 · Geometry

几何结构一致性

产品轮廓、辐条、孔位和比例

03 · Appearance

外观一致性

发型、服装、颜色、配饰、材质

04 · Style

视觉风格一致性

画风、摄影质感、线条和上色

05 · Spatial

空间与视角一致性

多角度对应同一三维结构

06 · Temporal

时间连续性

前后镜头的状态和动作衔接

07 · Brand

品牌一致性

Logo、字体、颜色与视觉系统

08 · Batch

批次一致性

多张图片遵守同一套生产规范

这八种一致性不一定同时成立。

例如，一个角色从动漫变成真人 Cosplay，可能保留角色设计的辨识度，但画风、真实面部细节和身体比例都会发生变化。

因此，最重要的第一步是：

把“同一个主体”拆分为必须固定的识别特征，以及允许变化的表现特征。

### 22.2 第一部分：角色设定图（Character Reference Sheet）

对于持续生成的动漫人物，建议首先制作一张标准角色设定图。

它相当于角色的视觉档案，而不是一张普通写真。

![鲸鱼娘开源资产库](https://images.openai.com/static-rsc-4/JjVE4XGQ5ZJZyD-zc9L6mjCpQu-3g5DNNiotB82N84KMRvu-fXmnd-C-cJcB2oaPPTlYd0wsQBJEUQdrS2aUKhvfnfjnsEDYkbC8bxdvRFHYjX3-OxDM61FNc5UE5DduBu8B-aX72TuOMdiIMjv3JOre4ouWfZNHgSk-ym2ih4s?purpose=inline)

角色设定图示意。不同视图应以经过确认的同一角色设计为依据，不能仅凭外观相似判断一致。

一套标准的角色设定图，建议包含：

| 内容     | 作用                         |
| -------- | ---------------------------- |
| 正面全身 | 确定角色正面设计与比例       |
| 侧面全身 | 确定轮廓、头发长度与服装侧面 |
| 背面全身 | 确定背部服装、发型与配饰     |
| 面部特写 | 确定眼睛、发际线和五官       |
| 配饰特写 | 确定头饰、蝴蝶结等关键设计   |
| 颜色样板 | 统一发色、瞳色和服装主辅色   |

对于我们此前使用的蓝发女仆少女，重点应该固定蓝色长发、瞳色、白色褶边头饰、蓝白服装以及鲸鱼主题配饰。

#### Character Bible：角色视觉档案

## Character Bible · BLUE-MAID-001

### 核心身份（P0）

角色：同一位成年蓝发女仆少女。

主要识别特征：

- 蓝色长发
- 蓝色眼睛
- 白色褶边女仆头饰
- 深蓝与白色女仆服装
- 鲸鱼主题元素

所有特征以经过确认的角色基准图为准。

### 设计一致性（P1）

- 保持发型主要轮廓和长度
- 保持服装主要裁片和装饰结构
- 保持关键配饰的位置及形状
- 保持原有角色比例和画风

### 允许变化（P2）

- 姿势
- 手势
- 表情
- 镜头景别
- 光照
- 背景
- 合理的头发与衣物运动

### 禁止事项

不擅自改变发色和瞳色。

不重新设计女仆服装。

不随意添加或删除关键配饰。

不把不同角色的面部特征混合进来。

### 验收

每次生成后，与角色原始参考图核对身份、发型、服装和配饰。

这里要认识一个很重要的概念：

角色设定图是控制依据，不是模型保证。

仅提供角色三视图，不能确保模型在每次生图中都严格保持所有设计细节。

#### 三视图为什么容易失败？

因为从正面图推断角色背面，存在信息缺失。

例如，原始参考图可能没有展示：

- 服装背部的蝴蝶结。
- 头发后侧的层次。
- 裙摆背面的花纹。
- 背部配饰的固定方式。

如果模型不知道这些细节，可能会自行创造。

因此，不能把 AI 推断出来的背面设计直接认定为角色原始设定。

#### 三视图生成的推荐顺序

1. 先确定正面基准。
2. 对缺失的侧面与背面设计进行人工定义或补充参考。
3. 再制作侧面和背面图。
4. 将通过验收的三视图作为后续统一参考。

#### 可复制三视图提示词

使用上传的蓝发女仆少女参考图作为唯一角色设计依据。

生成一张角色三视图设定板，包含正面、右侧面和背面全身图。

三个视图使用相同的人物身高基准、头身比例、服装设计、发型长度与主要配饰。

角色均自然站立，双臂轻微离开躯干，避免服装细节被手臂遮挡。

采用正交投影式角色设定图表现，尽量减少透视缩短。

白色背景，三栏等宽，人物从头顶到脚底对齐。

未在原始参考图中出现、且没有其他参考资料确认的背部设计，不应被当作已经核实的角色设定。

不添加其他人物，不随意改变服装花纹和关键配饰。

正交投影（Orthographic Projection）在这里是视觉目标。如果需要真正几何精确的正交三视图，仍然更适合使用同一三维模型进行渲染。

### 22.4 第三部分：表情一致性（Expression Sheet）

同一个人物可以拥有不同情绪，但必须尽量保持身份一致。

![けいゆう (@keiyuu_) on X](https://images.openai.com/static-rsc-4/lm7KB52gzAQvyaQt1pEf9iBhtlNeyPijyTvmsz5iGIpnrU0Mq4Y8qz7_EVY6nziTRpKsorfbSZQWcXrnTSubSzP-KKQK1zI0amZba-zJWiBm6yi3p0CxywvS1L7kXojjBfoJcrWLMu9CkLqcnZA0uaMHELOJL6c5ddJXrXcIK6M?purpose=inline)

建议表情集先从六种基本状态开始：

| 表情           | 控制特征               |
| -------------- | ---------------------- |
| 自然 Neutral   | 面部放松               |
| 微笑 Happy     | 嘴角上扬、眼部变化     |
| 惊讶 Surprised | 眼睛睁大、眉毛抬起     |
| 难过 Sad       | 眉眼下垂、嘴部收紧     |
| 生气 Angry     | 眉部压低、眼神集中     |
| 害羞 Shy       | 视线轻微回避、面颊变化 |

正式制作表情集时，建议固定头部角度、面部大小、光线和画风。

这样才能把实验变量集中在表情，而不是让模型一边改变表情，一边改变人物角度。

验收条件

### 22.6 第五部分：产品几何一致性（Product Geometry Consistency）

#### 产品一致性应该锁定哪些字段？

例如轮毂：

| 约束等级 | 项目       | 具体控制                           |
| -------- | ---------- | ---------------------------------- |
| P0       | 产品型号   | 必须为当前 SKU                     |
| P0       | 辐条与轮廓 | 不增加、不减少、不重新设计         |
| P0       | 孔位结构   | 螺栓孔与中心区域符合真实产品       |
| P0       | 规格参数   | 直径、宽度、PCD、ET 等以数据表为准 |
| P1       | 材质工艺   | 抛光、拉丝、哑光等区域一致         |
| P1       | 配色       | 黑银、哑灰等以实物为准             |
| P2       | 摄影表现   | 背景、光源、反射与阴影可调整       |

必须特别区分：图片无法单独证实轮毂的全部技术规格。

例如，ET 偏距、额定载荷及某些中心孔尺寸，必须通过可靠产品资料确认，而不能由 AI 根据照片推测。

### 22.7 第六部分：多角度产品图如何保持同一结构？

我们在第十七节已经学习了 Multi-view Product Display。

这一节则重点研究：不同视角是否真的来自同一个产品。

#### 三种一致性方案

方案 A · 单张参考图 + AI 多角度生成

输入一张正面图，由 AI 推断侧面或背面。

优点：创作方便。局限：遮挡面缺少真实信息，几何误差风险较高。

方案 B · 多张真实参考图 + AI 视觉编辑

提供同一个 SKU 的正面、斜侧、背面和细节照片。

优点：降低未知结构的推测量。局限：仍不能保证生成式几何完全准确。

方案 C · 真实三维模型 + 渲染

使用 CAD、经过验证的三维扫描或模型，从统一几何结构渲染多个角度。

优点：在模型准确的前提下，几何与视角一致性最好。适合高要求产品资料。

#### 如何选择？

对于博客概念演示，可以使用方案 A。

对于商品宣传，优先选择方案 B 或真实实物摄影。

对于需要严格多角度一致性的产品展示，优先选择方案 C。

最重要的是不要把 AI 根据单张照片生成的背面结构，当成经过确认的真实产品设计。

### 22.8 第七部分：多参考图的角色分工（Multi-reference Strategy）

多图参考不是把许多图片一起交给模型，让它自由组合。

而是明确每张图片提供什么信息。

多参考图的一致性控制流程



图片 A · 身份

人物脸型、发型、主要设计



图片 B · 服装

服装款式与关键配饰



图片 C · 姿态

身体与四肢位置



图片 D · 场景

空间、地形、环境光



目标图像

身份 A + 服装 B + 姿态 C + 场景 D

#### 多图组合的一个重要问题：参考冲突

例如：

- 图片 A 中角色头发是长发。
- 图片 B 中角色的服装模特是短发。
- 图片 C 中姿态人物穿黑色服装。

我们不希望模型把 B、C 中不相关的人物特征混入 A。

应该明确：

> 图片 A 是人物身份唯一依据。图片 B 仅提供服装设计。图片 C 仅提供姿态，不参考其中人物的外貌和服装。图片 D 仅作为背景参考。

每增加一张参考图，就应该增加一项素材职责说明。

但参考图越多也可能引入更多冲突；素材质量和明确性通常比数量更重要。

### 22.9 第八部分：如何减少主体漂移（Identity Drift）

主体漂移是指多次生成之后，人物或产品逐渐偏离初始参考。

例如：

概念示意，展示偏差可能积累的过程，并非所有多轮生成都会发生漂移。

#### 减少漂移的五个方法

1. 固定 Master Reference：每次都提供原始角色或产品基准图，不只依赖最新生成结果。
2. 维护 Reference Pack：将正面、侧面、服装和关键特写作为统一参考集。
3. 分离固定项和变化项：新一轮只改变动作、背景或指定参数。
4. 逐轮比较：对照原始基准，而不只是比较上一张。
5. 回退与重建：出现严重漂移时，从可靠版本重新开始。

#### 特别提醒：更多负面提示词不一定能解决漂移

如果模型缺少产品背面结构的信息，反复写“结构绝对不能改变”也不能使它知道真实背面应该是什么样子。

在这种情况下，补充可靠参考素材，比增加提示词限制更有帮助。

### 22.10 第九部分：单变量一致性实验

为了判断某种生成方法是否真的有助于保持角色一致性，建议采用控制变量实验。

例如，同一个蓝发少女分别生成四种姿态：

| 实验条件   | A    | B    | C    | D    |
| ---------- | ---- | ---- | ---- | ---- |
| 角色基准图 | 固定 | 固定 | 固定 | 固定 |
| 服装与画风 | 固定 | 固定 | 固定 | 固定 |
| 背景       | 固定 | 固定 | 固定 | 固定 |
| 画幅       | 3:4  | 3:4  | 3:4  | 3:4  |
| 动作变量   | 站立 | 坐下 | 挥手 | 转身 |

这样可以观察随着姿态变化，哪些角色特征最容易发生漂移。

不过，上面属于“动作变化对角色一致性的影响”实验。

如果要研究不同参考策略的效果，则应该固定目标动作，仅改变参考图条件。

例如：

- A 组：只提供文字描述。
- B 组：提供一张角色正面图。
- C 组：提供经过核实的多角度角色参考集。

每组尽量多次生成，并进行独立验收，避免将单次生成结果误认为普遍规律。

### 22.15 本节总结

本节的核心公式：

一致性控制 = 主参考图 + 固定身份与结构 + 允许变化的变量 + 多参考图职责 + 逐轮验收 + 版本回退。

通过这一节，我们建立了几个重要认知：

第一，一致性不等于每张图都长得一样。角色和产品的核心特征应稳定，而镜头、动作、场景和光照可以变化。

第二，参考素材比单纯增加提示词长度更重要。如果缺少真实产品背面资料，模型无法通过一段强约束提示词获得这些未知结构。

第三，人物一致性与工业产品一致性的标准不同。前者主要关注身份、外貌和角色设计，后者还必须考虑真实几何、制造规格与适配信息。

第四，多轮生成必须保持可追溯性。需要保留 Master Reference、模板版本及合格结果，防止错误在迭代过程中不断积累。
