##  第八节：参考图与一致性控制（Reference Image & Consistency）

GPT 生图从 0 到 1 · 第 08 课 · 图生图、多图参考、主体锁定与局部编辑

前七节，我们主要研究如何通过文字控制图片：比例、构图、风格、镜头、光影、材质等。

但进入真实商业生产后，会遇到一个更重要的问题：

如何让 AI 按照我们已有的图片生成，而不是每次重新创造一个看起来相似、实际上却不同的主体？

例如：

- 使用同一位蓝发少女生成不同姿势，不能每次都换脸。
- 将动漫角色转换为写实摄影，同时保留发型、服装和主要角色特征。
- 给汽车替换轮毂时，只能修改轮毂，不能改变车身。
- 把普通商品照片改成商业摄影图，但必须保留产品实际结构。
- 更换海报背景时，Logo、标题和二维码不能发生变化。

这正是第八节要解决的核心：参考图驱动的可控生图。

### 8.1 参考图不等于生成图

我们先建立三个概念：

| 概念       | 英文                | 核心作用                     |
| ---------- | ------------------- | ---------------------------- |
| 文生图     | Text-to-Image       | 通过文字创建新画面           |
| 图生图     | Image-to-Image      | 以现有图片作为生成或编辑依据 |
| 一致性控制 | Consistency Control | 尽量保持主体与关键特征稳定   |

需要注意，参考图并不自动意味着模型会逐像素复制它。

AI 可能正确理解“这是一辆汽车”，但改变它的灯组、轮毂、车身细节；也可能理解“这是同一个动漫角色”，却修改了眼睛、发饰或裙子图案。

因此，参考图控制不仅需要提供图片，还需要明确说明：

哪些内容作为视觉依据，哪些内容允许修改，哪些内容绝对不能改变。

### 8.2 参考图控制的六大核心能力

REFERENCE CONTROL SYSTEM

01 · Identity

主体一致性

人物脸型、角色身份、产品形态

02 · Structure

结构一致性

轮廓、几何、服装、物体细节

03 · Style Transfer

风格迁移

动漫转写实、摄影转插画

04 · Multi-Reference

多图参考

主体图、风格图、背景图组合

05 · Local Editing

局部编辑

替换、移除、增加特定区域

06 · Iterative Consistency

多轮一致性

多次修改、版本管理与回退

### 8.2 视觉叙事的八大控制维度

当任务从“生成一张图”扩展到“生成一组连续画面”时，提示词需要同时管理叙事、角色、场景和视觉语言。下面这八个维度可以作为检查清单，帮助我们定位连续画面中断裂的原因。

<VisualStorytellingFramework />

这张框架图适合在生成分镜、角色组图和连续视觉叙事时使用。每次修改只调整一个维度，更容易判断结果变化来自哪里。

本节我们建立一套控制逻辑：

图生图控制公式

参考素材 + 素材职责 + 保持项 + 修改项 + 禁止项 + 验收标准

它比单纯写“根据参考图生成”更明确，也适用于人物、产品、海报和场景编辑。

### 8.3 第一部分：主体一致性（Identity Consistency）

主体一致性解决的问题是：生成结果是否还是同一个人物或同一个产品？

#### 把角色拆成三个层级

| 层级     | 控制内容           | 示例                         |
| -------- | ------------------ | ---------------------------- |
| 核心身份 | 需要长期保持的特征 | 蓝色长发、蓝色眼睛、鲸鱼元素 |
| 角色设计 | 默认保持的视觉信息 | 女仆头饰、蓝白服装、蝴蝶结   |
| 可变因素 | 当前任务允许修改   | 动作、表情、视角、场景       |

这样，AI 才能区分“角色不能变”和“角色可以换动作”。

#### 示例提示词

使用参考图中的蓝发少女作为唯一角色依据。

**P0 核心身份：** 保持蓝色长发、蓝色眼睛、白色褶边女仆头饰、蓝白色女仆服装以及鲸鱼元素。保留参考图中的主要发饰和服装结构。

**P1 本次修改：** 将人物动作改为双手自然放在胸前，表情为轻微微笑。

**P2 可调整内容：** 发丝自然摆动、少量布料褶皱、符合新动作的阴影。

**固定条件：** 3:4 竖版，人物完整入镜，白色背景，原有动漫画风。

**禁止事项：** 不改变发色、瞳色、服装款式，不删除鲸鱼元素，不增加其他人物或多余肢体。

这里的 P0、P1、P2 是我们人为设定的任务优先级，不是模型保证逐项执行的技术开关。

### 8.4 第二部分：结构一致性（Structural Consistency）

人物一致性强调身份，而产品一致性往往更强调几何结构是否正确。

例如，一个锻造轮毂，其商业价值可能直接取决于这些细节：

- 辐条数量和形状
- 螺栓孔布局
- 中心盖设计
- 轮辋边缘结构
- 金属工艺及配色

产品参考约束分级

以轮毂为例

P0

结构

辐条、孔位、轮辋、中心盖不可重新设计

P1

外观

颜色、加工工艺、产品细节保持一致

P2

摄影表现

背景、阴影、光线可在指定范围内修改

这里存在一个重要边界：

生成式编辑不能保证产品几何结构与参考图像素级一致。

如果是实际销售的轮毂、踏板、电子产品等，尤其不能凭生成结果确认规格正确。

严格要求产品本体原样不变时，优先使用原图抠图、图层合成、背景替换等确定性编辑方式，再利用 AI 生成背景或环境素材。

### 8.5 第三部分：风格迁移（Style Transfer）

风格迁移是指：在保留主体某些核心信息的情况下，改变图片的视觉表现。

写实角色摄影

真实织物、发丝、皮肤和摄影光照

进行风格迁移时，必须先判断哪些东西是风格属性，哪些东西是角色身份属性。

例如：

| 保留           | 改变                                     |
| -------------- | ---------------------------------------- |
| 蓝发与蓝色瞳孔 | 由动漫上色变成真实头发与眼睛材质         |
| 女仆服装结构   | 由绘制裙子变成真实织物                   |
| 白色头饰       | 由二维线条变成真实蕾丝                   |
| 鲸鱼元素       | 由卡通图案变成可实现的服装装饰或造型道具 |

特别要注意，动漫人物的部分结构在现实摄影中可能没有直接对应物。比如非常夸张的头身比例、悬浮发丝或者不符合现实的配件，就需要确定是保留奇幻造型，还是转换成可实际制作的 Cosplay 道具。

#### 风格迁移提示词

以参考图中的蓝发女仆少女为角色设计依据，将二维动漫插画转换为真实 Cosplay 摄影。

**保持：** 蓝色长发、蓝色眼睛、白色褶边头饰、深蓝白色女仆服装、蝴蝶结与鲸鱼元素。

**改变：** 将二维动画上色改为真实皮肤、真实发丝、真实织物、自然面部光影与商业摄影质感。

**人物设定：** 一位成年女性 Cosplayer，保留参考角色的主要视觉识别特征。

**构图：** 3:4 竖版，正面全身照，居中，摄影棚浅灰色背景。

**约束：** 不重新设计主要服装结构，不擅自修改发色、瞳色和角色主要配件。避免塑料皮肤、明显动漫描边及不自然人体比例。

### 8.6 第四部分：多图参考（Multi-Reference）

单图参考只能提供有限的信息，而复杂任务可能需要几张图分别负责不同的内容。

例如，制作一张商业汽车海报时，可能需要：

- 图片 A：车辆外观与结构
- 图片 B：目标环境与背景
- 图片 C：品牌 Logo
- 图片 D：排版风格参考

多图参考最重要的不是上传多少张图，而是让每张图承担明确的职责。

#### 多图参考的任务分配

Multi-Reference Workflow



图片 A · 主体

负责车辆造型、产品结构、颜色



图片 B · 场景

负责背景环境、地形、光照氛围



图片 C · 品牌

负责 Logo 与品牌识别元素



图片 D · 版式

负责布局、留白与文字层级



目标图像（Final Image）

组合各参考图承担的特定信息，解决冲突后生成

#### 多图参考中的优先级

假设图片 A 的汽车是蓝色，而图片 B 的汽车是红色。

如果不明确指定，模型可能错误地把参考图 B 的车身颜色带入最终结果。

因此需要写：

> 图片 A 是车辆外观的唯一参考，车身造型与颜色以图片 A 为准。图片 B 仅用于参考环境与光线，不参考其中的汽车。图片 C 只用于品牌 Logo，不改变其内容。图片 D 仅用于布局参考。

通过素材职责隔离，尽量减少参考图之间的信息干扰。

#### 多图提示词模板

根据上传的多张参考图片，制作一张新能源汽车商业宣传图。

**图片 A——主体参考**

图片 A 是车辆外观的唯一依据，保持车型轮廓、车身颜色、前脸、灯组、轮毂以及车身比例。

**图片 B——环境参考**

仅提取背景环境、建筑空间和整体光线氛围，不参考图片 B 中的车辆与其他主体。

**图片 C——品牌参考**

使用图片 C 中的品牌 Logo，保持其颜色、文字、字形及图形比例。不得重新设计。

**图片 D——构图参考**

参考图片 D 的主体位置、标题区域与留白比例，不复制不相关的装饰内容。

**最终要求**

16:9 横版商业宣传图，车辆作为唯一主视觉，画面干净、专业。

当参考素材出现冲突时，车辆信息以图片 A 为准，品牌信息以图片 C 为准，背景以图片 B 为准。

对于需要 Logo、二维码、产品文字绝对准确的商业素材，建议由图像编辑或排版工具直接叠加原始文件，避免模型重绘造成错误。

我们可以把局部编辑分为四类。

| 编辑类型 | 英文    | 示例                     |
| -------- | ------- | ------------------------ |
| 替换     | Replace | 更换背景、轮毂、服装颜色 |
| 增加     | Add     | 给桌面增加一束花         |
| 移除     | Remove  | 去掉画面中多余的行人     |
| 调整     | Modify  | 修改人物手势或灯光       |

#### 局部编辑最关键的两个区域

编辑区域（Editable Region）：允许发生变化的地方。

保护区域（Protected Region）：应该尽量保持不变的地方。

#### 局部编辑提示词模板

以图片 A 为唯一基础图片进行局部编辑。

**本次唯一修改任务：** 将背景更换为柔和的浅蓝色渐变摄影棚背景。

**允许修改的区域：** 马克杯以外的背景区域，以及与新背景匹配的自然接触阴影。

**必须保持的区域：** 马克杯本体，包括杯口、杯柄、杯身、比例、颜色和表面材质。

**禁止修改：** 不改变杯子的形状，不增加图案，不改变镜头角度，不添加其他物品。

**输出要求：** 保持原图比例，主体位置一致，背景干净自然。

需要特别注意： 即使提示词明确写了“其他部分不变”，生成式图像编辑仍可能影响未指定区域。对精确度要求高的任务，应该结合遮罩、分层编辑或传统图像处理方法。

### 8.8 第六部分：多轮生图一致性（Iterative Consistency）

真实创作过程中，一张图片通常不会一次完成。

例如：

多轮图片编辑工作流

1. V1 · 创建基准图

   确定人物或产品外观、比例、构图。

   输出：Master Image

2. V2 · 修改背景

   以 V1 为依据，仅修改背景环境。

   检查：人物与产品是否发生变化

3. V3 · 调整光影

   以通过验收的 V2 为依据，修改光照。

   检查：材质、面部、品牌标识是否仍然正确

4. V4 · 加入排版

   使用已经确认的图片添加标题和品牌信息。

   推荐：采用独立文字图层

5. V5 · 最终验收

   检查主体、结构、文字、品牌、画幅及输出质量。

   输出：Final Asset

#### 为什么多轮修改可能越来越偏离原图？

因为每一次生成式编辑都可能带来微小变化。

假设第一次只想修改背景，但同时改变了角色发饰；第二次又以前一次的结果作为参考，模型就可能将错误发饰当成新的基准。

经过多轮迭代，最终图片可能逐渐偏离最初设计。

这种现象可以称为迭代漂移（Iterative Drift）。

#### 三个重要控制方法

1. 保存原始基准图：不要只保存最后一张生成结果。
2. 每轮只做一项主要修改：例如先背景、后光影，避免一次重构所有内容。
3. 定期与原图比较：发现主体结构漂移时，回到最近一个通过验收的版本。

对需要长期复用的角色，还可以建立固定的角色参考套图，包括正面、侧面、背面及关键服装细节。

### 8.9 一致性不是只有一种

我们可以把一致性拆分成六个独立的验收指标。

| 一致性维度     | 检查问题                         |
| -------------- | -------------------------------- |
| 身份一致性     | 是否还是同一个人物或角色？       |
| 结构一致性     | 轮廓、形状、服装结构有没有改变？ |
| 风格一致性     | 是否保持统一的摄影或插画风格？   |
| 场景一致性     | 背景空间、物体位置是否稳定？     |
| 品牌一致性     | Logo、字形、品牌颜色是否准确？   |
| 编辑范围一致性 | 是否只修改了指定的内容？         |

不同任务需要不同权重。

例如，人物写真优先关注身份一致性；轮毂商品主图需要优先关注结构一致性；品牌海报则需要关注 Logo 和文字准确性。

### 8.13 最重要的实战原则：生成控制与精确编辑分开

| -------------------- | ---------------------------- |

你需要掌握一个判断标准：

### 五、强制约束

P0：不改变车辆参考图中的主要车型特征。

P0：不重新设计产品参考图中的踏板结构。

P0：不修改原始 Logo 字形与品牌色。

P1：统一构图、光线、背景和视觉风格。

P1：车辆、踏板比例合理，安装位置符合对应产品适配资料。

P2：允许调整少量自然反射与接触阴影。

### 六、质量验收

检查车型是否正确。

检查踏板是否匹配产品 SKU。

检查产品结构与安装位置。

检查图片比例与主体占比。

检查文字与品牌标识准确性。

对于要求完全准确的 Logo、文字和产品细节，使用原始素材通过独立图层合成。

实际执行中，最好将 AI 负责的车辆与安装效果主视觉，和程序负责的品牌 Logo、标题及卖点排版分开。

这样不会因为生成某一台车型时，连固定 Logo 的位置、文字或字形都跟着发生变化。

### 7. 进一步升级：母版版本管理

建议引入一个叫做 Template Versioning（模板版本控制） 的概念。

例如：

| 模板版本 | 改动内容                 | 适用情况     |
| -------- | ------------------------ | ------------ |
| V1.0     | 基础白灰摄影棚模板       | 第一批商品图 |
| V1.1     | 车辆主体占比统一为约 80% | 第二批优化   |
| V1.2     | 修改统一灯光与阴影       | 新版本发布   |
| V2.0     | 重构商品标题区域与品牌栏 | 全新视觉规范 |

如果上司突然要求“所有图片顶部 Logo 再放大一点”，不应该重新生成全部汽车主视觉。

如果 Logo 是通过独立图层或排版模板合成的，只需修改排版模板，然后重新导出这批图片。

这正是把AI 生图、模板排版、变量管理拆开的价值。

### 本节最重要的结论

我们可以把它总结为一个非常实用的公式：

批量一致性生图 = 常量配置 + 行级变量 + 参考素材映射 + 母版提示词 + 自动化执行 + 质量验收。

当任务从 1 张图片扩大到 100 张甚至 1,000 张时，关键不再是每张图片的提示词写得有多长，而是能不能通过同一套生产规范，持续获得一致、可验收、可维护的结果。

这一部分建议作为第八节的 8.15「批量图片生成与变量化提示词」，也是整套博客从单张创作走向企业级视觉生产工作流的重要衔接。
