##  第二十一节：分辨率、清晰度与后期处理（Image Quality & Post-processing）

GPT 生图从 0 到 1 · 第 21 课 · 像素、DPI/PPI、锐化、降噪、超分辨率、色彩管理与商业图片交付

前二十节，我们已经掌握了 GPT 生图的主要视觉控制方法，包括构图、镜头、光影、材质、场景、动态、参考图、局部编辑和图文融合。

这一节，我们要解决一个在商业生图中经常被忽视的问题：

为什么一张在 ChatGPT 中看起来很清晰的 AI 图片，保存下来放大、上传网站或者拿去印刷后，却可能出现模糊、锯齿、噪点、文字失真和色彩偏差？

例如：

- 一张 1024×1024 的商品图，放大到 3000×3000 后细节变得模糊。
- 一张汽车网站 Banner，在电脑端很清楚，放到高分辨率显示器上却显得粗糙。
- 一张 A4 海报在屏幕上很好看，但印刷后文字不够清晰。
- 一张轮毂产品图经过过度锐化，金属边缘出现白边。
- 一张人像经过 AI 超分辨率处理后，皮肤毛孔和五官发生变化。

这些问题已经超出了提示词本身，涉及数字图像的技术质量与后期处理流程。

本节目标是建立从 AI 图片生成到正式交付的完整图像质量控制方法。

### 21.1 首先理解：一张图片的质量由什么决定？

商业图片质量可以拆分为六个维度。

IMAGE QUALITY CONTROL FRAMEWORK

01 · Resolution

分辨率

图片的实际像素宽高

02 · Sharpness

锐度与细节

边缘清晰度、纹理还原

03 · Noise & Artifacts

噪点与伪影

颗粒、压缩块、异常纹理

04 · Upscaling

超分辨率

放大与细节重建

05 · Color Management

色彩管理

色彩空间、色差与导出

06 · Export Quality

输出质量

文件格式、压缩与交付

我们需要先建立一个概念：

图片像素数量多，不代表图片细节一定真实。

一张 4096×4096 的模糊图片，仍可能不如一张细节准确的 2048×2048 图片。

#### 像素尺寸与图片比例的关系

| 比例 | 常见示例像素 | 使用场景               |
| ---- | ------------ | ---------------------- |
| 1:1  | 1024×1024    | 商品主图、头像         |
| 3:4  | 1200×1600    | 小红书图文、竖版产品图 |
| 4:3  | 1600×1200    | 产品说明、文章插图     |
| 16:9 | 1920×1080    | 网站 Banner、横版视觉  |
| 9:16 | 1080×1920    | 手机竖屏视觉           |

这些是目标输出尺寸示例，不代表 GPT Image 的所有接口都原生支持这些尺寸。生成时需要查看实际模型支持的规格，再使用适当的裁切、扩图或缩放处理。

### 21.3 第二部分：PPI、DPI 与印刷分辨率

这是一个非常容易混淆的概念。

#### PPI 与 DPI 不完全相同

- PPI（Pixels Per Inch）：每英寸包含多少图像像素，常用于表示数字图像对应实体尺寸时的像素密度。
- DPI（Dots Per Inch）：打印设备每英寸输出多少墨点，属于打印设备的成像特性。

在日常设计沟通中，很多人把 300 PPI 的图片口头称为“300 DPI 图片”，但从技术角度看，两者不是一回事。

#### 图片印刷尺寸如何计算？

印刷宽度（英寸）=像素宽度PPI印刷宽度（英寸）=PPI像素宽度

例如，一张 1200×1600 的图片，在 300 PPI 的目标下：

- 宽度约为 4 英寸。
- 高度约为 5.33 英寸。

也就是大约 10.16×13.55cm。

#### A4 印刷需要多少像素？

A4 纸张尺寸为 210×297mm。

在 300 PPI 下，完整 A4 页面大约需要：

A4 · 300 PPI

## 2480 × 3508 px

约 870 万像素，不含额外出血区域

但 300 PPI 不是所有印刷任务的绝对要求。大型海报、展板和远距离观看物料，可以根据观看距离采用更低的有效图像像素密度。

同样重要的是：在文件元数据里把 72 PPI 改成 300 PPI，并不会自动增加图像细节。

#### 锐化到底做了什么？

常见锐化算法并不是直接创造真实细节，而是增强局部边缘的对比，使画面看起来更清晰。

过度锐化可能产生：

- 边缘出现白边或黑边。
- 皮肤纹理过分粗糙。
- 金属高光周围形成异常轮廓。
- 图片噪点被一起增强。

#### 商品图的锐化原则

对于轮毂、汽车配件和电子产品，建议优先检查产品结构和真实纹理，而不是一味增加锐度。

尤其在锻造轮毂商品图中，辐条边缘清晰很重要，但不能为了锐化而改变真实的倒角或加工形态。

### 21.5 第四部分：降噪（Denoising）

噪点与纹理不是同一回事。

真实的皮肤毛孔、织物纤维、金属加工纹路属于我们希望保留的细节。

而随机色斑、明显的压缩块或不符合画面风格的噪声，可能需要处理。

#### 降噪过度的问题

当降噪强度太高时，容易产生“塑料感”。

例如：

- 人物皮肤被处理得像蜡像。
- 衣服纹理消失。
- 建筑墙面过度平滑。
- 金属表面丧失真实微小变化。

所以降噪应遵循：

去除干扰性噪声，但尽量保留真实材质细节。

### 21.6 第五部分：超分辨率（AI Upscaling）

超分辨率（Super-resolution）是利用算法将低分辨率图像转换为更高分辨率图像的过程。

图像放大示意

原始图像





4096 × 4096

4× 尺寸放大

宽高放大 4 倍，总像素数量变为 16 倍，但新增像素不意味着原始场景信息增加了 16 倍。

#### 传统插值与 AI 超分辨率的区别

| 方法             | 原理                         | 风险                 |
| ---------------- | ---------------------------- | -------------------- |
| 最近邻插值       | 根据相邻像素直接放大         | 容易出现明显像素块   |
| 双三次插值       | 通过周围像素进行平滑估算     | 可能偏软             |
| Lanczos 等重采样 | 利用滤波重建采样结果         | 可能出现振铃伪影     |
| AI 超分辨率      | 基于学习到的图像规律重建细节 | 可能生成不存在的纹理 |

#### 商业产品图片要注意什么？

AI 超分辨率可能会“补充”细节，但某些细节并非真实存在。

例如：

- 在轮毂上生成不存在的细小刻字。
- 改变人物眼部与皮肤纹理。
- 在织物上创造错误的纹路。
- 改变 Logo 的边缘或细微字形。

因此，超分辨率适合增强一般视觉素材，但不应作为还原无法看清的真实产品参数、刻字或结构的证据。

### 21.7 第六部分：图片格式与压缩（Image Formats）

常见的图片格式包括 JPEG、PNG、WebP 和 AVIF。

| 格式 | 特点                     | 适用场景                 |
| ---- | ------------------------ | ------------------------ |
| JPEG | 有损压缩，兼容性广       | 摄影图片、一般网页图片   |
| PNG  | 无损压缩，支持透明通道   | Logo、界面素材、精确图形 |
| WebP | 支持有损、无损和透明     | 网站与电商图片           |
| AVIF | 高效压缩，支持透明等特性 | 现代网站的优化图片       |
| SVG  | 矢量图形格式             | Logo、图标、可缩放图形   |

一个经常出现的错误是：

> 把 JPEG 图片另存为 PNG，认为画质就会恢复。

实际上，PNG 只能无损保存当前像素，不能恢复 JPEG 已经丢失的信息。

#### 推荐的文件选择

对于网站和电商图片，可以考虑：

- AI 生成主视觉：保存高质量原始版本。
- 编辑中间文件：保留无损格式或分层工程文件。
- 网站展示：根据实际兼容性使用 WebP、AVIF 或 JPEG。
- 透明品牌 Logo：优先使用原始 SVG 或高质量透明 PNG。
- 需要印刷的最终物料：按照印厂要求导出符合规范的 PDF 或其他文件格式。

### 21.8 第七部分：色彩空间与色差（Color Management）

为什么同一张蓝色汽车图片，在不同设备上看起来可能不一样？

这与屏幕、色彩空间、色彩配置文件以及环境光有关。

#### 三种需要认识的色彩概念

| 概念       | 说明                                          |
| ---------- | --------------------------------------------- |
| sRGB       | 网页与普通数字图片广泛使用的标准 RGB 色彩空间 |
| Display P3 | 覆盖部分更广色域的显示设备常用空间            |
| CMYK       | 印刷中常用的减色油墨颜色模型                  |

例如，某些高饱和蓝色在屏幕上非常鲜艳，但用普通印刷工艺可能无法完全重现。

不能把 RGB 转为 CMYK 就理解成“印刷颜色一定准确”。

实际印刷还受到纸张、油墨、设备、ICC 配置文件与印刷工艺影响。

#### 色彩管理的基本原则

1. 明确图片最终用于屏幕还是印刷。
2. 尽量保留或正确转换 ICC 色彩配置文件。
3. 网络展示通常优先考虑 sRGB 的兼容性。
4. 印刷素材按印厂提供的色彩规范处理。
5. 对颜色准确性要求高的品牌素材，进行必要的实物打样。

### 21.9 第八部分：不同场景的图片输出策略

同一张 AI 图片，不应该直接无差别地用于所有渠道。

| 输出渠道         | 常见比例          | 关键要求                     |
| ---------------- | ----------------- | ---------------------------- |
| 微信小程序商品图 | 1:1               | 商品清楚、文件大小合理       |
| 小红书图文       | 3:4               | 中文文字清晰、手机可读       |
| 网站 Hero        | 16:9 或响应式构图 | 主体不被裁切、加载速度合理   |
| 博客正文         | 根据内容选择      | 细节可读、适配正文宽度       |
| A4 产品手册      | A 系列纸张比例    | 有效印刷像素密度、准确文字   |
| 大型展会背景     | 按实际安装尺寸    | 观看距离、印刷工艺、素材质量 |

#### 网站图片的额外注意事项

对于网站 Hero，除了图片本身的像素尺寸，还应考虑：

- 电脑与手机是否使用不同的裁切。
- 图片格式和压缩质量。
- 页面加载速度。
- 响应式图片。
- 重要内容是否位于安全区域。
- Logo 和标题是否由 HTML/CSS 单独渲染。

例如，产品视觉图的主体可以由 AI 生成，但网站大标题和 CTA 按钮通常更适合通过网页组件实现。

### 21.10 第九部分：AI 图片后期处理的正确顺序

建议将商业图片的后期处理拆成六个步骤。

1. 质量预检查

   查看原始图片的结构、文字、产品真实性与明显伪影。

2. 结构与局部修复

   先处理错误边缘、局部瑕疵或背景问题。

3. 颜色与光影校正

   调整白平衡、对比度、亮度和色彩一致性。

4. 降噪与适度锐化

   减少噪点，保留真实纹理。锐化通常结合最终尺寸进行。

5. 尺寸调整与超分辨率

   根据目标输出要求缩放或增强分辨率，并重新检查细节。

6. 图文合成、导出与验收

   加入准确文字和品牌素材，按目标渠道输出并检查。

这是一种实用的流程参考，不是所有编辑软件必须采用的固定操作顺序。例如，某些超分辨率算法包含自己的降噪与锐化，可能需要调整处理顺序，避免重复增强。

### 21.15 本节总结

本节的核心公式是：

商业图像质量 = 有效像素 + 真实细节 + 合理锐化与降噪 + 正确色彩管理 + 合适压缩格式 + 输出验收。

最重要的四个认知：

1. 高像素不等于高清晰度。 像素数量、真实细节与视觉锐度属于不同概念。
2. AI 超分辨率不等于真实细节恢复。 它可能增强观感，也可能创造并不存在的细节。
3. 后期处理要尊重产品真实性。 不能为了画面清晰而修改真实产品结构。
4. 输出渠道决定最终质量标准。 网站、电商、社交媒体与印刷物料需要不同的尺寸和文件策略。
