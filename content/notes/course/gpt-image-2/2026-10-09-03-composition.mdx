## 第三节：构图控制（Composition）——从居中构图到复杂多主体布局

GPT 生图从 0 到 1 · 第 03 课 · 视觉构图基础

这一节，我们将从汽车、马克杯切换到少女肖像摄影，使用你上传的照片作为统一参考案例，系统研究不同构图方法如何改变一张图片的视觉效果。

本节的核心目标是：

学会控制主体在画面中的位置、大小、空间关系与视觉重心，而不只是告诉 AI“生成一张好看的少女照片”。

### 3.1 什么是构图（Composition）？

构图，是指画面中人物、背景、空间和其他视觉元素的组织方式。

例如，同样是一位黑色长发少女：

- 居中构图：突出人物，视觉稳定。
- 对称构图：强调秩序和平衡。
- 三分法构图：突出空间关系，给画面留白。
- 四宫格布局：通过四个画面展示不同表情或角度。
- 九宫格布局：用九个画面叙述人物、情绪和细节。
- 复杂多主体布局：控制多个人物或多个视觉对象之间的主次、位置与互动。

这里需要特别区分：

三分法是一种单幅画面的构图原则，而四宫格、九宫格通常是多画面编排方式。 九宫格也可以指用于单幅构图的 3×3 辅助网格，两种含义不要混淆。

### 3.3 六种构图方式的学习顺序

| 构图方法       | 视觉特点           | 适合场景             |
| -------------- | ------------------ | -------------------- |
| 居中构图       | 直接、稳定、聚焦   | 头像、人物封面       |
| 对称构图       | 规则、均衡、正式   | 时尚写真、杂志摄影   |

### 3.4 第一种：居中构图（Centered Composition）

![AI Hairstyle - Free Hairstyle Try On App | Virtual Haircut](https://images.openai.com/static-rsc-4/p6086WW6mRx8cBAREFeboXGb20l5TbSpKMHHDJC7vH_lqFc2pAtz2PU7ZUjwNgEkXOqY4ej1u-GXkxRt-x66ENajKQPkkeNjoe8Y3eBaZSub4xtxLqSggrnD6QP4F3zAXL7ySWw1OiQ_bb74qpMW8VEbRxfdet8JjutaxavL30w?purpose=inline)

核心原理：将视觉主体放在画面中心，使观众的注意力集中到主体上。

对于少女肖像，建议从眼睛、鼻梁、脸部中心和头肩位置来控制主体的视觉重心。

典型参数：

- 主体中心：画面宽度 50% 附近。
- 头部大小：根据特写、半身照等景别确定。
- 背景：尽量简洁。
- 留白：头顶与四周保持协调。

示例提示词 · 居中构图

一张 3:4 竖版少女肖像摄影。参考上传照片中的人物外貌、黑色长发与自然妆容。采用居中构图，人物面部位于画面中央，视线自然看向镜头，头肩完整可见。浅灰色室内背景，柔和自然光，真实手机人像摄影风格。保持人物面部特征一致，不添加其他人物与装饰。

### 3.5 第二种：对称构图（Symmetrical Composition）

![广州曙光王娟医生联系方式公开！预约双眼皮修复15600元起,整形修复-8682整形网](https://images.openai.com/static-rsc-4/aMvzyJfWb-6CpnCBVKgAGDGQHqE6yjYo7kfNBUr2Uq2JeOA1knqZyh6PsreCokceGLxjP34WYYh4bSbyU7kAQX58UOH0USXiiBSuUTHSMHyUhRrtBCM7q0Sl70PZTqVd6P7m1VC3phqnd19DkIGIQbt31GNLKmJQdjb9BnxFuc0?purpose=inline)

对称构图与居中构图最大的区别在于：

居中构图强调主体位置，对称构图强调画面元素在某条轴线两侧的视觉平衡。

例如正面少女肖像，可沿鼻梁建立垂直中轴线，让人物姿态、背景建筑、光线与空间尽量呈现对称关系。

对称不一定意味着完全镜像。人脸和发丝自然存在细微差异，过度追求镜像可能让人物变得僵硬。

示例提示词：

> 以参考照片中的少女为主体，使用严格的纵向对称构图，人物正面朝向镜头，面部中心与画面垂直中轴线重合。背景左右均衡，光线柔和且分布对称。保持真实面部结构与自然发丝，不进行机械镜像处理。

在少女肖像中，三分法可以有两种常见用法：

- 将人物放在左侧三分线附近，右侧保留背景空间。
- 将人物的眼睛安排在上方三分线附近，让面部成为焦点。

示例提示词：

> 生成一张 3:4 竖版自然风少女肖像。采用三分法构图，人物位于画面左侧三分线附近，双眼位于上方三分线附近。人物看向画面右侧，右边保留干净的浅灰色背景空间，整体氛围柔和、真实、自然。

### 3.7 第四种：四宫格布局（2×2 Grid）

四宫格不再是单幅照片的构图，而是多视图编排（Multi-panel Layout）。

02 侧面肖像

03 俯视视角

04 情绪特写



眼神和面部细节

四宫格应统一人物身份、服装与整体视觉风格，但每格可以设置不同的视角或情绪。

示例提示词：

> 使用参考照片中的少女作为统一主体，生成一张 2×2 四宫格人像摄影作品。四格分别展示正面肖像、侧面肖像、轻微俯视以及眼神特写。每格保持相同的发型、服装和人物外貌特征。统一柔和自然光、浅灰色背景和写实摄影风格。四格大小一致，间距统一，不添加文字与其他人物。

这里有个重要技巧：每个格子都应该明确分配任务。

只说“生成四宫格少女写真”，模型需要自行判断每格展示什么。写出每格的画面内容，通常更容易得到符合预期的布局。

九宫格特别适合人物设定、情绪板和连续视觉叙事。

示例提示词：

> 生成一张 3×3 九宫格少女写真拼图，人物以参考照片为准。九格依次展示：正面近景、左侧脸、右侧脸、低头、自然微笑、凝视镜头、头发特写、眼睛特写、半身肖像。所有画面保持同一人物的外貌特征、发型与服装一致。统一色温和写实摄影风格，九格等大、间距均匀、无边框文字。

要注意：九宫格会同时增加人物身份一致性、局部细节与排版的控制难度。如果需要严格一致，实际项目中可以先分别生成，再用排版工具合成。

### 3.9 第六种：复杂多主体布局（Multi-subject Composition）

当画面中存在两个人物或者多个独立主体时，构图需要增加三个控制维度：

主体数量、主体位置、主体关系。

例如，一张双人少女摄影作品：

| 控制项目 | 描述方式                   |
| -------- | -------------------------- |
| 主体数量 | 画面恰好两个人             |
| 主次关系 | 左侧人物为主，右侧为辅     |
| 大小关系 | 主体人物稍大，次要人物稍小 |
| 空间层次 | 主体在前景，次要人物在中景 |
| 互动关系 | 两人自然交流，不看镜头     |

示例提示词：

> 生成一张 16:9 横版双人时尚摄影作品。左侧人物以参考照片中的少女为准，位于前景，占据主要视觉空间。另一位原创少女位于画面右侧中景。两人具有明确的前后层次和自然互动。保持主体间距，避免肢体重叠或面部融合。画面中恰好出现两个人，不添加背景路人。
