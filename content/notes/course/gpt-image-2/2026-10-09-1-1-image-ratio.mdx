## 第一节：图片比例（Aspect Ratio）

### 1.1 什么是图片比例？

图片比例，就是一张图片的宽度与高度之间的比例关系。

例如：

- 1:1：宽度与高度相等，正方形。
- 3:4：宽度为 3，高度为 4，竖版。
- 16:9：宽度为 16，高度为 9，横版宽屏。

### 1.2 图片比例与图片分辨率的区别

这是初学者最容易混淆的两个概念。

| 概念       | 含义                   | 示例              |
| ---------- | ---------------------- | ----------------- |
| 图片比例   | 宽和高的关系           | 1:1、3:4          |
| 图片分辨率 | 图片的像素尺寸         | 1024×1024         |
| 图片质量   | 清晰度、纹理、细节表现 | Low、Medium、High |

例如，`1024×1024` 和 `2048×2048` 都是 1:1 的正方形，但是第二张图片的总像素数是第一张的 4 倍。

核心原则：图片比例决定构图空间，分辨率决定像素数量，画质还取决于模型、质量设置和生成内容。

### 1.4 GPT Image 2 支持哪些比例？

根据 OpenAI 官方文档，`gpt-image-2` 支持自定义输出尺寸，并不只局限于固定的三种比例。

主要技术限制如下：

- 宽度和高度必须为 16 的整数倍。
- 画幅比例范围为 1:3 至 3:1。
- 单边最大 3840 像素。
- 总像素数必须介于 655,360 和 8,294,400 之间。

官方常用尺寸包括 `1024×1024`、`1536×1024`、`1024×1536`。



这里要注意：设计所需比例与 API 实际支持的像素尺寸是两回事。 比如 1200×1600 符合 3:4 的比例，也是符合上述尺寸约束的示例；但 1080×1920 中的 1080 不是 16 的整数倍，因此不能直接作为该 API 的 `size` 参数。

### 1.6 如何在提示词中指定图片比例？

初学者可以使用这个结构：

提示词公式

画面用途 + 图片比例 + 主体内容 + 构图要求 + 留白要求

例如，制作一张新能源汽车电动踏板商品主图：

生成一张 1:1 正方形汽车配件电商商品主图。

**主体内容：** 一台安装了电动踏板的新能源汽车，采用三分之四侧前视角。

**构图要求：** 车辆位于画面中央偏下，完整展示车身轮廓，重点突出踏板的安装位置。

**背景要求：** 纯白到浅灰渐变背景，采用高级汽车配件商业摄影风格。

**排版要求：** 顶部预留约 20% 的空间用于商品标题，画面简洁、产品清晰，不添加无关元素。

如果通过 API 生图，建议同时设置 `size` 参数；仅仅在提示词里写入比例，并不等于已经精确指定输出像素尺寸。

### 1.7 新手常犯的三个错误

1. 先生成图片，后考虑使用平台。 原本横向的车身图片被强行裁剪成竖版，容易出现车头、车尾缺失。
2. 认为分辨率越高，生成效果就一定越好。 提高像素数量并不能自动解决产品结构错误、文字错误、构图不合理等问题。
3. 只写比例，不写构图。 比如仅要求 3:4，模型不一定知道需要在哪里放标题、在哪里留白，最终仍然可能不适合发布。

### 本节知识总结

图片比例不仅是技术参数，也是构图决策。对于商业生图，最好在开始生成前就确定发布平台、图片比例、主体位置和文字区域。
