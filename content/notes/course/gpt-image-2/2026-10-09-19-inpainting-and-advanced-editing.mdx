## 第十九节：局部重绘与高级编辑（Inpainting & Advanced Editing）

GPT 生图从 0 到 1 · 第 19 课 · 局部重绘、遮罩控制、扩图、对象移除、背景替换与多轮精修

前十八节，我们已经掌握了如何从零开始生成一张图片，以及如何控制人物、产品、场景、光影和连续分镜。

现在进入一个在实际工作中非常重要的领域：

当一张图片已经有 90% 满意时，如何只修改剩下的 10%，而不是重新生成整张图片？

例如：

- 一张人物写真很满意，只想把背景从摄影棚换成内蒙古草原。
- 一张汽车宣传图已经完成，只需要把车身从白色改成蓝色。
- 一张产品海报布局正确，但其中一块文字需要替换。
- 一张商品照片中有多余物体，需要去掉并自然补全背景。
- 一张 1:1 电商图片，需要扩展成 16:9 网站 Banner。
- 一张汽车照片需要替换轮毂，同时保持车型、车身和背景不变。

本节的核心是从 Generation（生成）转向 Editing（编辑）。

### 19.2 局部编辑的核心：Editable 与 Protected

这是本节最重要的基础概念。

图像区域控制系统

Editable Region

允许被修改的区域，如背景、局部配件或指定颜色

Protected Region

希望保持的区域，如人物面部、产品本体、Logo

例如，给马克杯更换背景：

> 将杯子以外的背景修改为浅蓝色摄影棚背景，保留杯身、杯柄、杯口、材质与原始比例。

这属于文字级区域控制。

但需要注意，文字描述的保护区域不等于真正被锁定的像素。即便提示词强调不改变杯子，生成式编辑仍可能对杯柄或杯口产生微小变化。

对于必须原样保留的内容，应该使用实际遮罩、透明图层或确定性图像合成。

### 19.3 第一部分：遮罩编辑（Mask-based Editing）

遮罩（Mask）是图像编辑中的一个核心工具。

它用于指定哪些像素属于选中区域。

黑白遮罩仅用于说明选区概念。不同软件与接口对黑白、透明区域的编辑含义可能不同，必须遵循具体工具的遮罩规则。

#### 遮罩编辑的四个关键参数

| 参数          | 含义                                 |
| ------------- | ------------------------------------ |
| Mask Region   | 实际需要编辑的区域                   |
| Mask Boundary | 选区边缘                             |
| Feathering    | 边缘羽化，降低接缝突兀程度           |
| Context       | 遮罩之外的场景信息，用于保持视觉协调 |

例如要替换汽车轮毂：

应该精确选中需要修改的轮毂金属部分，而不是把整台车一起选中。

但实际操作中，若新轮毂需要改变原有边缘遮挡和透视，选区还可能需要留出少量过渡空间。

#### 高级技巧：边界羽化

如果选区边缘过硬，修改后的区域可能出现明显接缝。

如果羽化范围过大，又可能侵入本应保持不变的主体。

所以不应该默认使用越大的羽化越好，而应该根据物体边缘情况设置。

例如：

- 车身金属边缘：要求边界清晰。
- 头发与背景：需要处理大量半透明和细小发丝。
- 柔和阴影：允许渐变过渡。
- Logo：通常应保持原始清晰边缘，不依赖生成式羽化。

#### 如何编写移除提示词？

普通描述：

> 去掉花瓶。

精确描述：

> 移除桌面中央的红色花瓶，包括花瓶本体和对应投影。根据周围区域自然补全木质桌面的纹理、颜色、透视与光照。保持桌子、墙面、摄影角度和其他物品不变。

#### 移除物体的三个检查点

1. 被移除物体是否完全消失，包括残留的影子或反射？
2. 背景纹理是否连续，例如桌面木纹是否突然断裂？
3. 是否误删与目标相邻的其他物体？

对于涉及真实事件或证据用途的照片，还应谨慎处理移除行为，避免让编辑后的图片错误呈现实际发生过的情况。

#### 背景替换的三个难点

主体边缘

人物头发、透明玻璃、网状结构等边缘较复杂，容易出现残留背景或边缘发白。

光线匹配

如果原图中的人物受到强烈暖光照射，却直接换成冷色摄影棚，可能出现环境不协调。

接触与投影

替换背景后，地面接触阴影、反射和物体支撑关系可能需要重新处理。

#### 背景替换 Prompt

以图片 A 为唯一主体外观参考。

本次任务：将原始背景替换为纯白至浅灰色无缝商业摄影棚。

**保持不变：**
主体的外观、颜色、比例、结构、材质和主要细节。

**允许修改：**
背景区域、与新环境匹配的接触阴影，以及必要的边缘过渡。

**光影要求：**
背景与主体的照明协调，保留真实材质反射。

**禁止：**
不改变产品结构、颜色、Logo、型号或主体拍摄角度。

**验收：**
检查主体完整性、边缘清洁程度、接触阴影与背景自然程度。

如果产品本体必须像素级保持一致，应采用原图抠图与背景合成，而非重新生成主体。

### 19.6 第四部分：画面扩展（Outpainting）

扩图是指在原始图片的画布范围之外，生成新的环境内容。

例如：

- 将 1:1 商品图片扩展为 16:9 网站 Hero。
- 把竖版人物写真扩展成横版电影画幅。
- 给海报顶部增加标题留白。
- 将汽车展示图向右扩展，为 CTA 按钮预留空间。

从 1:1 扩展至 16:9 的布局示意

新增左侧背景

原始主体区域

新增右侧背景

示意只说明扩展区域。实际保持原始内容不裁切时，需要根据原图尺寸计算左右新增画布大小。

#### 扩图与裁切有什么区别？

| 操作             | 作用                     |
| ---------------- | ------------------------ |
| Crop 裁切        | 删除画布的一部分         |
| Resize 缩放      | 改变图像尺寸             |
| Outpaint 扩图    | 在原有边界之外补充新画面 |
| Recompose 重构图 | 重新安排主体和视觉元素   |

例如，原始图片主体位于中央，但你希望变成左侧汽车、右侧文案的 Hero。

这可能不仅需要扩图，也需要改变主体在新画幅中的相对位置。

#### 扩图提示词

以参考图片为基础进行画面扩展。

**原始主体：** 保持汽车本体及原始拍摄角度不变。

**目标比例：** 16:9 横版。

**扩展方向：** 优先向画面右侧增加背景空间，为网站标题与 CTA 按钮预留大面积干净留白。

**环境延续：** 沿用原图的浅灰色汽车摄影棚背景、地面透视、主光方向与环境反射。

**主体保护：** 不重新设计车辆前脸、灯组、轮毂、车身颜色和比例。

**禁止：** 不在扩展区域添加其他车辆、人物、文字、Logo 或复杂装饰。

**结果要求：** 原始画面与新增区域过渡自然，不出现接缝、重复建筑或不协调的地面透视。

### 19.8 第六部分：多轮修复与编辑漂移（Iterative Editing）

一个很常见的问题是：我们越改越不满意。

例如：

第一次：更换背景。

第二次：修改灯光。

第三次：调整产品颜色。

第四次：修复产品边缘。

到了第四次，原来的产品细节可能已经发生变化。

这种问题可以称为编辑漂移（Editing Drift）。

安全的多轮编辑流程

1. V0 · 原始主图

   保存不可覆盖的原始参考图。

2. V1 · 背景修改

   只更换背景，验收产品是否保持一致。

3. V2 · 光影调整

   从已经验收的版本出发，修改指定光影区域。

4. V3 · 局部细节

   单独修复边缘、材质或接触阴影。

5. V4 · 排版合成

   通过独立图层加入文字、Logo 和其他品牌信息。

#### 为什么不能无限迭代？

因为每一轮生成式编辑都可能重新解释画面中的某些内容。

如果上一轮出现微小错误，下一轮又将该结果作为新的参考，就可能积累错误。

建议遵循三个原则：

保存原图、每轮限定修改范围、每轮验收后再继续。

如果发现关键产品结构漂移，应该回到最近的合格版本，而不是不断叠加“不要改变结构”的提示词。

### 19.9 第七部分：何时应该放弃生成式编辑？

这是本节很重要的工程判断。

不是所有图片修改都应该交给 AI 生成模型。

| 任务                   | 更合适的方法               |
| ---------------------- | -------------------------- |
| 去除背景里的普通杂物   | 局部重绘或修复             |
| 人物换成森林背景       | 抠图、合成或生成式背景替换 |
| 为人物修改发型         | 参考图驱动局部编辑         |
| 扩展草原风景           | Outpainting                |
| 将海报标题改为指定中文 | 真实文字图层               |
| Logo 必须完全正确      | 原始 Logo 叠加             |
| 二维码需要保持可扫描   | 原始二维码无损合成         |
| 商品形状不能改变       | 原图抠图或准确三维渲染     |
| 汽车轮毂必须严格还原   | 基于真实产品图片的精准合成 |
| 复杂产品结构拆解       | CAD 或经过核实的结构资料   |

可以建立一个决策逻辑：

本次编辑是否允许一定的生成误差？

允许

### 19.14 本节知识总结

本节最重要的公式是：

高级图片编辑 = 编辑目标 + 精确选区 + 保护区域 + 视觉融合 + 结果验收 + 版本管理。

我们需要掌握四个关键原则：

1. 明确编辑范围，比无限增加提示词长度更有价值。
2. 局部编辑的成功取决于“改对了什么”和“保住了什么”。
3. 生成式修改并不保证像素级保真。 对关键产品、Logo、二维码等元素，优先使用原图图层和确定性合成。
4. 多轮编辑必须能够回退。 不要让每一轮的微小错误不断累积。

至此，我们已经能够完成从初始生图到局部精修的主要操作。
