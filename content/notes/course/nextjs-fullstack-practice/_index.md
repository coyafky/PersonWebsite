## 课程定位

这门课的重点在**顺序**：按一个真实项目推进的次序讲，而不是按 API 分类讲。

所以它从「怎么创建一个页面」开始，到「怎么让搜索引擎抓到」结束，中间每一环都带着取舍说明——为什么用这个渲染模式、为什么缓存要调、为什么构建放在服务器上。

## 学习路线

1. **路由** —— 约定式路由、四种跳转方式、参数怎么拿
2. **文件约定** —— page、layout、loading、middleware 各管什么
3. **渲染** —— 静态、动态、流式，其实是三个时间点
4. **缓存** —— 默认缓存，以及四个新鲜度刻度
5. **优化** —— next/font 的五个 display 值、Image 的四条增强
6. **主题** —— CSS 变量 + 三态，以及为什么需要压水合警告
7. **滚动** —— 平滑滚动，以及「只存在于客户端的状态」怎么处理
8. **数据与登录** —— mongoose 建模、NextAuth 三步
9. **部署** —— 打包、SSH 部署链、nginx 与 pm2
10. **SEO** —— metadata、sitemap、OG 卡、语义化、robots
