# 打通两套技能池，和一条六步视频流水线

## 🧰 技能体系互通

上午做了一件基础设施的事：**让两套技能池互相看得见**。

- 37 个项目级技能全部软链到全局挂载，但**开发源仍留在 git 仓库里** → 版本管理不丢
- 顺带修正了一个认知：实际加载路径和以为的不一样，全机器技能总量 **335+**
- 再软链 2 个路由技能 + 8 个工具技能过去 → **两边的技能池互通**，两个集合在那一边也完整可用

**决策**：软链而非拷贝 —— 改一处两边生效，不会出现"改了 A 忘了 B"。

## 🎬 六步视频流水线

新建了一条流水线技能，把「做一条视频」拆成六步，**每步产物落盘**：

```
选题 → 脚本 → 分镜 → 【画面画布 + 主体人物】 → 关键帧 prompt(JSON) → 整段视频 prompt
```

三条铁律：

| 铁律 | 理由 |
|---|---|
| 画面提示词**必须是 JSON** | 六要素结构可追溯 |
| `beats` 支持同镜头一次多帧 | 省抽卡次数 |
| **画布先于 prompt** | 先定构图规格，再写提示词 |

## 🚗 第一个完整项目跑通

一个 30 秒品牌片：原厂车「没毕业」→ 升级舱 → 六大装备装甲化 → 毕业时刻 → 品牌收口。

六步完整执行，其中 **S03 用 `beats` 一次出了 6 帧**（轮毂/底盘/踏板/窗膜/改色/车衣），每帧独立提示词，全部 JSON 校验通过。

⭐ **一处关键的自我修正**：场景最初设计成「科幻升级舱」，后来**改成了真实的高端改装车间**（四柱举升机 + 六大施工工位）——因为科幻感和「到店施工交付」的品牌定位是脱节的。**形式上更炫，但跟生意对不上，就得改。**

## 🚙 资产库补全

- **母车资产**：身份锁（现代中国新能源 / 贯穿灯组 / 银灰金属漆 / 无 Logo）+ 两态（原厂态 / 毕业态六装备）+ 两套生成提示词
- **新场景**：升级车间
- 至此资产库完整：主角 34 + 轮毂萌物 + 场景 5 + 母车 + 表情包，三个项目全配齐

## 🎬 抖音文案采集：双通道部署

调研了现成的方案（抽音频 → 转写 → 分段 + 爆款维度分析 → 写回表格），然后做了两条路：

| 通道 | 做法 | 场景 |
|---|---|---|
| 附件版 | 部署到服务器，剪辑同事共用 | 批量上传 |
| URL 版 | 纯 Node 脚本，解析链接 → 去水印下载 → 转写 → 落表 | **丢个链接就全自动** |

修了原版一个鉴权缺失的 bug，并做了两处工程加固：

- **术语校正词表** —— 转写经常把车型名听错，自动纠正
- **幂等去重** —— 按视频 ID 判重，重跑不重复写库

**踩坑记录**（后来都成了经验）：

- 表格命令行工具某个参数不支持跳过确认，会**静默失败**
- 用 `head` 截断输出会触发 SIGPIPE **把 node 进程杀掉** → 只能 `nohup` + 写日志，这是唯一稳的跑法

## 📊 账号风格分析体系

- 用架构图把「丢链接 → 全自动 → 文案进库」画成泳道图（员工 / 机器人 / 文案库三层）
- 账号风格分析技能：**关键验证通了** —— 注入登录态后可以 API 翻页拉全量（**未登录只能拿到 21 个**）
- 批量解析：全量采集 + 高赞转写 + 多维风格画像

**实测结果**：某同行账号 **88 个视频全量采集**，12 个高赞转写（成功 11），生成 7 维风格报告。

⚠️ **一个排坑**：把 2 万字文案整个塞给小模型 → **输出直接乱码**。修法是只取前 600 字 + 换模型 + 禁止表格嵌套。

**爆款公式（从数据里看出来的）**：数字套餐名 + 车型 + 痛点提问 + 地域标签 + 功能前置。

作品清单也表格化了：全量 88 行 + 按赞数 TOP50 —— **人看表挑，再定向提取**，比全量跑便宜得多。

## 关键决策

| 决策 | 理由 |
|---|---|
| 37 个技能软链挂载，开发源留 git | 子项目也能用，版本管理仍在源 |
| 用软链互通两套技能池 | 目录同构，一条命令即注册 |
| 画面提示词必须 JSON + beats 一次多帧 | 可控可追溯 + 省抽卡 |
| 场景改真实车间 | 科幻感与「到店施工交付」定位脱节 |
| 采集做 URL 版 + 附件版双通道 | 丢链接全自动 / 批量上传两不误 |
| **提取与报告解耦** | 转写是重活，只跑一次；报告随时重跑复用 |
| 幂等去重 + 术语词表 | 重跑不重复写库、品牌词自动纠错 |
