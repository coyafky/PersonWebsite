# 蓝小辉 IP 资产库建成，轮毂宇宙开张

## 🎬 AI-Video 生产体系落地

把「用 AI 做视频」从零搭成一套可复用的体系：**5 大模块 35 个文件**——`workflow/`（16 步流程 11 篇）、`assets/`（六大 Bible）、`templates/`（4 个模板）、`playbooks/`（5 个专题）、`projects/`。

四条核心思想，后来一直沿用：

| 原则 | 含义 |
|---|---|
| **Asset Lock** | 先建世界，再拍摄 |
| **Reference First + Prompt Second** | 有参考图优先，提示词其次 |
| **Shot Card 六要素** | 每个镜头卡按固定六项写 |
| **Consistency Score ≥0.90** | 一致性不达标就不进剪辑 |

## 🐱 蓝小辉 IP 资产库（38 个 JSON）

下午把 IP 资产库建完，这是后面所有内容产出的地基：

- **五视角**（front / left45 / right45 / side / back）—— 母版 `CHAR_LANXIAOHUI_TECH_LION_001`
- **表情库** 8 个（EXP_01~08）
- **动作库** 10 个（POSE_01~10，06 平板 / 07 轮毂 / 10 麦克风带道具）
- **道具库** 7 个（平板 / 轮毂 / 扳手 / 车钥匙 / 漆面检测灯 / 直播麦克风 / 方案板）
- **场景库** 3 个（接待区 / 改装车间 / 无尘贴膜车间）

**完整配方**：`VIEW_XX 角度 + EXP_XX 情绪 + POSE_XX 动作（+ PROP_XX 道具）= 镜头主角资产调用`。

每个 JSON 都带 `generation_prompt`，可直接生图；全部语法校验通过。创世资产还差三个：产品、母车、门店。

## 🚗 两个轮毂广告创意项目

**projectOne《别扔！你的旧轮毂可能是钱》**

创意线：旧轮毂 → AI 轮毂 ATM → ￥￥￥ → 新轮毂 → 车变身。分镜 5 镜：抱轮毂进门 → 蓝小辉冲出 → 轮毂 ATM 三 beat（记忆点）→ 车变身 → CTA。

这天定下画风：**Q 版萌系 2.5D 动漫风**（三渲二 cel-shading、大眼星点高光、表情包感、高饱和）。

**projectTwo《轮毂逃跑了》**

原厂轮毂长小短腿逃跑「兄弟们快跑！」→ 蓝小辉追 → 轮毂急刹「你早说啊」→ 滚回门店置换 → 车帅气出门。

新角色 **轮毂萌物**：五辐轮毂 + 大眼 + 小短腿，**绝不人形化**（人形化就丢掉了「轮毂」这个本体），四只一组带头戴蓝橙领结。

另外试了一条 15 秒整片图生视频的路子：传首帧 + 全剧情 prompt 一次出片。

两个项目串成一个世界观——轮毂会跑 + 轮毂 ATM = **蓝辉轮毂宇宙**。

## 😺 微信表情包 16 个

母版 + 16 个表情 JSON（微信标准 240×240 透明底）：你好 / 收到 / 点赞 / 好嘞 / 谢谢 / 666 / 震惊 / 无语 / 生气 / 大哭 / 大笑 / 卖萌 / 加油 / 晚安 / 摸鱼，外加一个「**置换吗？**」（抱轮毂道具，品牌梗软植入）。

和 AI 视频共用同一套蓝小辉身份锁 → 多端 IP 保持一致。

## 📄 晚间：用文章代替 PPT

- 当天工作日志 → 网页文章（tufte 主题 10 节）
- 周工作汇报 → HTML 当 PPT（12 页 PDF）

**决策**：AI 时代不折腾传统 PPT，直接用 Beautiful Article 写 HTML 当 PPT——起因是 PPTX 导出反复卡死。

## 🛠️ 工作台搭建启动

晚上开始读项目的代码结构，为 Alma 写专属理解文档；并设计了工作日志技能的雏形（每日整理 + 每周草稿）。

当时验证出一个结论：**活动记录当天是空的，靠对话沉淀下来的记忆笔记才是正确路径**——后来这套技能确实就是按这个思路长出来的。

## 关键决策

| 决策 | 理由 |
|---|---|
| 每个变体独立 JSON 提示词 | 可分别喂 AI 生成、版本可追溯 |
| 画风统一 Q 版萌系 2.5D | 全项目复用同一套风格尾缀 |
| 轮毂萌物绝不人形化 | 保持「轮毂」的识别度 |
| 世界观串联 | 可延伸成系列 |
| 15s 整片 vs 分镜拼接双轨 | 平台支持就一次出片，否则拆段拼 |
| 用 HTML/PDF 替代传统 PPT | 更快更可控 |
| 工作日志数据源 = 对话总结优先 | 活动记录为空时唯一可行路径 |
