# 选择性色彩 · 橙色太阳镜

**一句话概括**：让画面里唯一保留的颜色成为绝对视觉焦点。

**8 维拆解**：

| 维度 | 内容 |
|------|------|
| 主体 | 戴橙色太阳镜的肖像 |
| 风格 | 时尚肖像 |
| 构图 | 近景肖像 |
| 光影 | 柔和影棚光 |
| 色彩 | 黑白环境 + 橙色点缀 |
| 技术 | 选择性色彩 |
| 氛围 | 酷、聚焦 |
| 参数 | 1:1 方形 |

> 选择性色彩是最容易出效果的技巧之一：模型对"唯一色彩"的理解通常很稳定，也是判断模型色彩控制能力的试金石。
