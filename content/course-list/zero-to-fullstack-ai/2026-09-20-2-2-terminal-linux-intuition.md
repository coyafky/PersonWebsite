## 课时概要

终端本质上只是另一种和电脑交互的方式——不再靠鼠标点来点去，而是直接告诉电脑「你现在要做什么」。很多人第一次看到终端的反应是「一堆英文、会不会把电脑弄坏」，但实际上它的操作逻辑非常简单，唯一需要克服的是心理恐惧，上手 30 分钟就能建立基本感觉。

## 本节要点

- 终端 / 命令行 / CLI / Terminal，入门阶段当成同一类东西：直接用文字指挥电脑。
- 文件夹在终端里叫「目录」：打开文件夹叫「进入目录」，查看文件叫「列出当前目录」——概念没变，说法换了。
- 最重要的感觉：**你现在正处在哪个位置**——很多命令默认对「当前位置」生效，一迷路就先 `pwd`。
- 九个命令 + 三个路径符号：`pwd` / `ls` / `cd` / `mkdir` / `touch` / `cat` / `rm` / `rmdir` / `clear`；`~` / `/` / `..`。
- Vim 生存四步：`i` → 写 → `Esc` → `:wq`（保存退出）或 `:q!`（不保存退出）。
- `rm` 没有确认框，删之前先 `pwd` + `ls` 确认。

## 笔记正文（讲义整理）

### 终端到底是什么

终端、命令行、CLI、Terminal，入门阶段先当成同一类东西。核心特点是：你不再靠鼠标点来点去，而是直接告诉电脑「你现在要做什么」——进入某个文件夹、看当前有什么文件、创建新文件、运行程序、连接远程服务器。

### 为什么软件开发要用终端

图形界面当然也能干活，但一串「建多级文件夹 + 建文件」的操作，在终端一行就完：

```
mkdir -p ~/Projects/zero2tech && touch ~/Projects/zero2tech/index.html
```

远程服务器没有漂亮桌面，只能靠命令操作；AI 时代更是——把命令和报错贴给大模型，它最容易理解你当前的环境。所以终端不是「高手专属工具」，而是后面整条开发路径最基础的工作方式。

### 终端和文件、路径的关系

上一节的概念没变，只是说法换了：

- 文件夹 → **目录**
- 打开文件夹 → **进入某个目录**
- 查看文件夹下面的文件 → **列出当前目录里的文件**

### 最重要的感觉：我现在在哪

终端里很多命令都默认对「你当前所在的位置」生效：你在哪个目录、新建的文件会出现在哪、命令会对谁起作用。所以只要一迷路，就先问自己一句：**我现在在哪个路径下？**

### 入门命令速查

| 命令 | 作用 |
| --- | --- |
| `pwd` | 看当前路径（我在哪） |
| `ls` | 看当前目录里有什么 |
| `cd 目标` | 进入某个目录 |
| `mkdir 名字` | 创建目录 |
| `touch 名字` | 创建文件 |
| `cat 文件` | 查看文本文件内容 |
| `rm 文件` | 删除文件 |
| `rmdir 目录` | 删除空目录 |
| `clear` | 清空终端画面 |

三个马上遇到的路径符号：`~` 家目录、`/` 根目录、`..` 上一级目录。比如 `cd ~` 回家目录，`cd /` 去根目录，`cd ..` 回上一层。

### Vim 生存指南

这是这一节最经典的一步：用 `vim hello.txt` 打开文件后：

1. 按 `i` 进入编辑，输入内容（比如 `hello terminal`）
2. 按 `Esc` 回到普通模式
3. 输入 `:wq` 回车 = 保存退出；`:q!` 回车 = 不保存退出

被困在 Vim 里别慌，记住这四个键就够了。

### 删除命令，先有一点敬畏

`rm` 不像图形界面那样弹确认框。刚开始养成习惯：删之前先 `pwd` 看清自己在哪、`ls` 看清目录里有什么，确认无误再删。不是终端可怕，而是终端很直接。

### 什么叫 Linux 直觉

不是「学完就会 Linux 了」，而是这种感觉：目录是一层一层的、你做的动作总在某个路径下发生、很多开发工作本质上是在处理文本文件、服务器通常只有终端没有桌面。这一节就是在提前适应后面的工作环境。

## 和之前 GFG 笔记的连接

终端命令是「人直接敲」，GFG 笔记里的 Python `os` 模块就是「用代码做同一件事」，两边一一对应：

| 终端命令 | Python 里的对应（GFG 笔记） |
| --- | --- |
| `pwd` | `os.getcwd()`——脚本从哪个文件夹跑起来的 |
| `cd` | `os.chdir(path)`——代码版切换目录 |
| `ls` | `os.listdir(path)`——列出目录内容 |
| `mkdir` / `mkdir -p` | `os.mkdir()` / `os.makedirs()`——含缺失父目录时用后者 |
| `touch` | `Path.touch()`——`pathlib` 里创建空文件 |

详细代码例子见 GFG 笔记：[OS Module](https://www.geeksforgeeks.org/python/os-module-python-examples/)、[Directory Management](https://www.geeksforgeeks.org/python/python-directory-management/)。

## 关键概念

- **终端 / CLI / Terminal**：用文字命令和电脑交互的方式，不靠鼠标点。
- **目录**：终端里对「文件夹」的叫法。
- **CWD**：当前所在目录，终端和 Python 里的相对路径都相对它解析。
- **`~` / `/` / `..`**：家目录 / 根目录 / 上一级目录。
- **Vim 生存模式**：`i` 插入 → `Esc` 普通模式 → `:wq` 保存退出 / `:q!` 放弃退出。

## 代码 / 实操

按讲义完整走一遍这条闭环（在家目录下）：

```
pwd                        # 我在哪
cd ~                       # 回家目录
pwd
ls                         # 这里有什么
mkdir terminal-practice    # 建练习目录
ls
cd terminal-practice       # 进入它
pwd
touch hello.txt            # 建文件
ls
cat hello.txt              # 空文件，cat 不报错只是没内容
vim hello.txt              # i → 写 hello terminal → Esc → :wq → 回车
cat hello.txt              # 看到刚写的内容
rm hello.txt               # 删文件（先 pwd + ls 确认）
cd ..
rmdir terminal-practice    # 删空目录
ls
```

## 我的收获

1. 终端不神秘，就是「用文字指挥电脑」——唯一要克服的是心理恐惧，30 分钟就能上手。
2. 迷路的解决方案永远只有一个：先 `pwd` 看我在哪——很多时候不是命令失效，而是站错了位置。
3. `rm` 没有后悔药，删之前先 `pwd` + `ls` 确认，是终端时代的安全带。
