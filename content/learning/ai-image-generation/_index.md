# AI 生图学习

这个专题记录我在 **AI 生图**上的系统学习。目标是把生图从「攒模板的玄学」变成「可解释、可复现、可积累」的技能。

笔记围绕四个能力展开：

- **原理**：AI 到底怎么画出图的（Diffusion 心智模型）
- **参数**：seed / CFG / 步数 / 采样器 各自控制什么
- **提示词**：句式结构、风格锚点、视觉语言
- **工程**：生图 API、批量生成、自动化管线

每篇笔记都尽量配「配套阅读练习」，把知识点挂到真实场景（Hermes 生图链路、米醋 API、Seedream），而不是空谈概念。
