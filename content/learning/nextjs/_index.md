# Next.js Learning

这个主题用于整理我对 Next.js 的系统学习：不是只记 API，而是把它放回 Web 应用工程的上下文里理解。

## 我想解决的问题

学习 Next.js 的目标不是“会用一个框架”，而是弄清楚现代 Web 应用为什么需要框架，以及框架到底替我处理了哪些复杂度：

1. 页面路由和布局如何组织
2. 服务端渲染、静态生成和客户端渲染如何取舍
3. 数据获取、缓存、重新验证如何影响用户体验
4. API、表单提交和 Server Actions 如何组成全栈能力
5. 部署、性能优化和元数据如何进入生产流程

## 学习路径

- 先理解 Next.js 的定位：React 之上的全栈 Web 框架
- 再学习 App Router：文件系统路由、layouts、pages、loading、error
- 然后理解渲染模型：Server Components、Client Components、静态/动态渲染
- 最后进入工程化：数据获取、缓存、metadata、部署、测试
