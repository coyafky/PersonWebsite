模块 2.4 · 服务器实战

从你的电脑到公网页面

租一台 Ubuntu 云服务器，SSH 远程登录它，Nginx 把它变成任何人都能访问的网页。

你的 Mac（终端）

SSH 登录进去操作它

ssh ubuntu@IP
:22 远程登录
敲命令、改文件

云服务器（Ubuntu）

另一台电脑，无屏幕、24h 开机、跑 Linux

22 · SSH 登录口 80 · Nginx 网页口
:80 访问网页
看 Welcome to nginx!

任何人的浏览器

输入公网 IP 就能打开

http://公网IP

买完拿到的三样东西

  • 公网 IP：别人能找到你的地址
  • 用户名：通常 ubuntu 或 root
  • 密码：登录用，输时屏幕不显示

云控制台放行两个端口

  • 22：SSH 登录要走（安全组 / 防火墙）
  • 80：浏览器访问要走（最容易漏！）
  • 不放行就连不上 / 打不开
ssh ubuntu@公网IP # 远程登录（端口 22）
sudo apt install nginx -y # 装 Nginx
systemctl status nginx # 看到 Active: active (running)
这一次，2.3 的整条链路（浏览器 → IP → 服务器 → 端口 → 内容）真的跑通了。
