模块 4.1 · 现代前端第一步

模块化：把两个灾难一起治了

同一个 anime.js、同一份 HTML/CSS，换的只是怎么组织代码——这就是「工程化」。

改造前 · 传统 script

全堆全局，顺序手排
<script src="…anime.iife.min.js"></script>
<script src="js/cards.js"></script> # 顺序错一格就崩
<script src="js/score.js"></script>
  • 暗依赖：cards.js 用 anime 却没声明，顺序只藏在排列里
  • 全局污染：anime 挂在 window 上，库一多就撞名
  • 双击 index.html 就能跑

改造后 · ES 模块

明文 import / export，各文件小柜子
<script type="module" src="js/main.js"></script>
# main.js 里：
import { animate } from "…anime/+esm"
  • 明依赖：谁依赖谁写在文件顶部 import，浏览器自己算顺序
  • 作用域隔离：同名 animate 各活各的，撞不上
  • 必须走服务器（3.5 那台 Nginx），不能 file:// 双击
