把四个点串起来：Mac → GitHub → 云服务器 → Nginx 80 端口 → 任何人的浏览器。

git push

↓

云服务器

~/zero-to-tech

Nginx :80
→

任何人的浏览器

http://公网IP

404 破案：Nginx 以 www-data 的身份读文件

Nginx 想读 /home/ubuntu/zero-to-tech/index.html
→
走到 /home/ubuntu 发现权限 drwxr-x---，others 是 ---，被挡住
→
修一次：sudo chmod o+x /home/ubuntu
给 others 开「能穿过、不能列目录」的缝
// 以后每次更新，就这三步

浏览器：Cmd+Shift+R 强刷
