模块 4.4 · 数据驱动界面

界面照着「值」显示——值的三种玩法

值存在哪儿，决定了它会不会自己变、刷新丢不丢、能不能分享。
玩法 1 · 从外面喂

props + 数据分离

值存哪：集中在 site.js，由父组件读出来喂进去
  • 组件空出位置，喂什么字就显示什么字
  • 所有文案收进 src/data/site.js 这张内容表
  • 组件只管怎么显示，不写死文案
  • 改文案只动这一个文件；做多语言再备一份表
demo：改 site.js 的 heroTitle 保存，大标题当场变，组件一行没碰。
玩法 2 · 自己揣着

state 状态

值存哪：组件自己的内存，有默认值、允许改
  • 不是外面喂的，是组件用着用着自己变
  • 值一变，界面当场跟着重渲染
  • React 内部替你盯着这个值——这是它的引擎
  • App 记住「当前在哪页」也是 state
demo：输入框打字，下面「已输入 N 字」当场跟着跳。
玩法 3 · 写进网址

URL 路由

值存哪：浏览器地址栏的 URL 里
  • state 存内存，刷新就清空——路由不能这么存
  • 把「在哪页」写进 URL：/text-lab
  • 刷新不丢、链接能发、前进后退都好使
  • 真实项目用现成库 react-router（认得名字即可）
demo：点「文字实验室」地址栏变 /text-lab，刷新、复制给朋友都还在。
