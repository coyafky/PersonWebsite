撞上的墙 → 四件事

① 配置抽离：.env 不进 git，.env.example 进 git

nohup 四零件

& 丢后台，终端不干等
nohup no hang up，不随 SSH 死
> backend.log 接住输出不丢
2>&1 错误输出并进同一文件
上线了但很朴素：nohup 不重启不自愈、8000 裸奔无日志无加密、前后端跨源——这三件正是 7.2 要换的（systemd + Nginx 反代同源）。
