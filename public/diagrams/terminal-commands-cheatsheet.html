终端命令速查

不靠鼠标点，直接用文字指挥电脑——一迷路就先问：我现在在哪个路径下？

① 定位

pwd我在哪（当前路径）
ls这里有什么（列出文件）

② 移动

cd 目标进入某个目录
cd ~回家目录
cd /去根目录
cd ..回上一层

③ 创建

mkdir 名字建目录
touch 名字建文件

④ 查看

cat 文件看文本内容
Tab命令自动补全

⑤ 删除

rm 文件删文件
rmdir 目录删空目录
⚠ 没有确认框！删之前先 pwd + ls

⑥ Vim 生存四步

i 编辑→ Esc→ :wq 保存退出
乱输了想跑？按 :q! 不保存退出。
路径符号 ~ 家目录 / 根目录 .. 上一级 ./ 当前
练习闭环：走一遍就不黑箱
mkdir terminal-practice → cd 进去 → touch hello.txt → vim 写内容 → cat 看结果 → rm / rmdir 删除
终端不是高手专属——它是后面整条开发路径最基础的工作方式。
