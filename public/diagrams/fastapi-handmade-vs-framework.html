5.3 亲手写过每一行，所以现在能确切知道框架替我们藏了什么。

同一个 GET /api/profile

if self.path == ... 路由判断→@app.get("/api/profile") 一行装饰器
self.send_response(200)→自动
send_header("Content-Type", ...)→自动设 JSON 类型
json.dumps().encode()→自动把 dict 序列化成 JSON
else 兜底 404→自动回 {"detail":"Not Found"}

FastAPI —— 管「接口该做什么」

定义路由、声明请求形状、自动校验
@app.get("/api/profile")
def get_profile(): return profile

uvicorn —— 管「让接口跑起来」

守端口、收请求、交给 FastAPI
fastapi dev # 自动挡（= uvicorn main:app --reload）
两个顺手福利：① /docs 自动长出接口文档，代码一改文档跟着变；② POST 的请求体用 BaseModel 一句 text: str 声明，自动解析+校验——字段错了回 422，我们自己代码写错回 500，谁的错状态码分得清。
读报错先看最后一行（什么错），再往上找 main.py 的行号（在哪儿）；读不懂整段丢给 AI。
