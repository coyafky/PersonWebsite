模块 4.2 · Vite 与 npm

构建工具夹在中间做翻译

你写源码（多文件），Vite 把它变成浏览器要的 dist（少文件、带 hash）。

你写的源码

js/cards.js
js/score.js
js/nav.js
js/main.js
css/ ── 8 个文件
Vite 做三件事
① 本地起服务器，保存即热更新
② 碎文件合并：8 css → 1，多 js → 1
③ 文件名加 hash，内容变名字变，缓存失效

devDependencies · 脚手架

npm install -D vite

开发时帮你干活的工具（Vite），盖完房就撤——上线的网站里没有它。

dependencies · 砖

npm install animejs

网站运行时真要用的库（anime），被打进 dist 随之上线。

// 三条命令，写在 package.json 的 scripts 里
npm run dev # 开发：localhost:5173 热更新
npm run build # 上线前：产出 dist/
npm run preview # 本地验 dist 产物
源码 ≠ 运行代码：永远改源码再 build；node_modules 和 dist 写进 .gitignore。
