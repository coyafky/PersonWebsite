一个组件 = 一个 UI 单元

数据原文 / 分数 / 判断等要显示的内容
结构return 里的 JSX 标签层级
样式className 指向外部 CSS
行为useEffect 里的入场动画
大小写大写开头是组件（<Nav />），小写是原生标签（<article>）。
props 传参<PageHeading title="…" />，同一组件喂不同参数就复用。
createRoot进入 React 世界的门，整个项目只在入口做一次。
拆组件只为「能复用」或「更好读」，别为了专业而拆。
浏览器最后拿到的还是 HTML/CSS/JS——React 只是写起来更舒服，Vite 负责翻译。
