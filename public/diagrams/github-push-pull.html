模块 3.4 · GitHub 与远程同步

本地 ↔ 远程的双向同步

本地 Git 管历史，GitHub 存副本——push 上传、pull 拉回。

你的 Mac（本地仓库）

一串 commit 存档点，随时可回退

~/zero-to-tech
push ↑
git push 把存档上传
pull ↓
git pull 把更新拉回

GitHub（远程仓库）

云端可信副本：备份 · 协作 · 部署拉取

git@github.com:你/zero-to-tech.git

私钥（留在本地，别外传）

~/.ssh/id_ed25519

证明「我是我」的钥匙，谁持有谁能连。

公钥（贴到 GitHub）

~/.ssh/id_ed25519.pub

可公开，GitHub 拿它认你的身份，免密码推送。

git remote add origin git@github.com:你/zero-to-tech.git # 挂钩远程
git push -u origin main # 第一次推送，建立跟踪
git add . && git commit -m "…" && git push # 日常三步
本地 + 远程双备份，代码再也不会因为电脑出事而丢。
