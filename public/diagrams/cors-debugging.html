面孔一：简单 GET（直接发）

3000 → 直接发 GET 到 8000
后端收到、回 200
没许可 浏览器不让网页 JS 读这份响应
解法：allow_origins=["http://localhost:3000"]

面孔二：带 JSON 的 POST（先问后发）

3000 → OPTIONS 预检（浏览器自动发）
问：允许这个源？允许 POST？
第一次 方法不在名单 → POST 根本没出门
解法：allow_methods=["GET","POST"]
通过后 真 POST 才发出，结果区更新
源 = 协议 + 域名 + 端口；3000≠8000 就是跨源。CORS 是浏览器的规则——curl 不是网页，所以一直畅通。写死的后端地址收进 .env.local：NEXT_PUBLIC_API_BASE_URL（可进浏览器，不能放密钥；改完要重启 dev）。
