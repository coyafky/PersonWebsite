模块 2.3 · 互联网是怎么工作的

输入网址后发生了什么

浏览器看到的一切，都要先找到那台服务器——这是一条七步链路。
从按下回车，到网页出现
1

你的浏览器

在地址栏输入域名

github.com
→
请求：域名是哪台？
2

DNS 翻译官

把域名翻译成 IP

140.82.121.3
→
请求：按 IP 找服务器
3

那台服务器

通过端口连上具体服务

IP : 443
←
响应：返回网页内容
4

浏览器显示

读取并渲染成网页

你看到的页面

域名

github.com

给机器地址起的好记名字——给人记、给人输入用。

IP 地址

140.82.121.3

一台联网设备在网络中的地址——机器之间找路用。

DNS

翻译系统

你输的是域名，它负责把域名翻译成 IP。

端口

80 / 443

同一台服务器上不同服务的入口：80 普通网页，443 加密网页。

本地网页是同一套：html 文件就是网页内容，浏览器负责读取并显示。当你打开本地文件时，「服务器」其实就是你自己的电脑——远程访问，只是把这台电脑换成了另一台。
浏览器发出去的叫请求（request），服务器回来的叫响应（response）。
