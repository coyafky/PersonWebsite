venv 工作流 + 前后端工具对照

每个项目一套自己的 Python：建、激活、装包、干、退出。装包前先看提示符 (zero-to-tech) 在不在。

venv 生命周期（在 backend/ 里）

1python3 -m venv --prompt=zero-to-tech .venv
建虚拟环境（--prompt 自定义提示符）
2source .venv/bin/activate
激活，提示符变成 (zero-to-tech)
3pip install requests
装包只进这个项目的 .venv；pip show 确认 Location
4python3 api_demo.py
干活——运行 .py 文件，不用构建
5deactivate
退出；.venv 不进 Git，requirements.txt 进 Git

前端 ↔ 后端 工具对照

npm↔pip
node_modules/↔.venv/
package.json↔requirements.txt
