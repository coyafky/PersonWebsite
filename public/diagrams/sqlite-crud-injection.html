模块 6.4 · SQLite 与 SQL

SQL 五件套 + 注入 vs 占位符

一个数据库就是硬盘上一个 .db 文件；Python 标准库自带，不用起服务。
选型落点：关系型（结构化小数据）+ 嵌入式（单应用、不养服务）→ SQLite。手机里微信聊天记录、浏览器历史底下都是它。

① 建表 CREATE TABLE

CREATE TABLE films (id INTEGER PRIMARY KEY AUTOINCREMENT, title TEXT, ...)
id 自增主键；日期/布尔 SQLite 用 TEXT / 0-1 凑

② 插入 INSERT

INSERT INTO films (title) VALUES (?); conn.commit()
commit 才落盘；datetime('now') 是函数不加引号

③ 查询 SELECT + WHERE

SELECT * FROM films WHERE language = ?
WHERE 是筛选条件；fetchall() 一次拿成列表

④ 排序限量 ORDER BY / DESC / LIMIT

SELECT * FROM history ORDER BY created_at DESC LIMIT 10
只说要什么，怎么排怎么快数据库自己安排

危险：拼用户输入

"WHERE title = '" + keyword + "'"

片名是 ' OR '1'='1 时，引号提前闭合，'1'='1' 永真——整表被吐出来。

安全：? 占位符

"WHERE title = ?", [keyword]

值单独交给 execute，数据库认定 ? 处铁定是值，什么符号都只当数据。

DELETE 千万别漏 WHERE（否则清空整表）。LIMIT 10 只攥 10 把椅子、按页读盘、索引提前排序——所以百万行排序也不爆内存。下一节在项目里真正用起来。
