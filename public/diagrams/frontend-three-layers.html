模块 3.1 · 前端基础 HTML

一个网页里的三层代码

同一个 index.html 文件里，同时住着三种语言，各管一摊。

HTML

内容和结构 · 页面上有什么
<body> 里的标签
骨架
尖括号标签组织内容：标题、段落、按钮。head 放元信息，body 放显示出来的东西。

CSS

样式和外观 · 这些东西长什么样
<style> 里的大括号 {}
妆造
选择器 + 规则：白底变卡片、居中、按钮变蓝。浏览器只按 .card 这条规则套样式。

JavaScript

行为和交互 · 发生事该做什么
<script> 里的函数
动作
onclick 触发 changeText()，getElementById('msg') 找到元素、改掉文字。
