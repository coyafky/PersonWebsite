DeepSeek：让大模型回句话

要 API Key（sk- 开头），按用量计费
curl https://api.deepseek.com/chat/completions \
  -H "Authorization: Bearer sk-..." \
  -d '{ "messages": [...] }'
choices[0].message.content = "你好，我是 DeepSeek…"
AI 时代到处是 API：AI 产品本质是调大模型 API；AI Agent 联网的工具（查天气/发消息/喊另一个模型）基本都是在调 API。回到我们的网站：前端调自己写的后端，也是一次 API——下几节我们就用 Python 把它写出来。
格式标准让 API 与语言无关——DeepSeek 不关心我们用 curl 还是 Python。
