## 展示需要解释的代码

代码块支持文件名、行号和重点行。窄屏可横向滚动，复制按钮只复制代码正文。

```typescript title="workflow.ts" showLineNumbers {2-3}
const draft = {
  status: "draft",
  needsReview: true,
  source: "user-outline",
};
```

## 对比同一配置的写法

<CodeTabs label="配置格式" items={[
  { label: "JSON", language: "json", filename: "workflow.json", code: '{\n  "status": "draft",\n  "needsReview": true\n}' },
  { label: "YAML", language: "yaml", filename: "workflow.yaml", code: 'status: draft\nneedsReview: true' }
]} />

两份代码表达相同的约束。可以用左右方向键切换选项，也可以按 Home 和 End 跳到首尾。
