# 企业 AI 应用与营销作品集 UI 验收

日期：2026-10-14

## 设计决策

主参考为 [RICOUI / Airtable](https://design.ricoui.com/brands/airtable)。采用浅色背景、适中字重、深色主按钮、工作流展示与案例组织；保留 Coya 的蓝色交互色和中文阅读习惯。比较过 RICOUI 的 Notion 参考，其多色产品营销风格不作为主视觉。完整规范见仓库根目录 `design.md`。

求职方向由用户明确为「企业 AI 应用与营销」。首页精选销售助理、营销内容管线和业务知识库；既展示交付，也明确原型、使用阶段及业务限制。

## 本轮交付

- 首页：岗位定位、可切换的真实项目流程、三个重点案例、工作方法、近期写作和联系入口。
- 关于页：能力、项目、教育和工作经历直接展示；补充 STAR 材料单独折叠；支持打印和保存 PDF。
- 全站：中文导航、页脚、集合页、案例和文章阅读样式、画廊及工具目录统一。
- 阅读：每个表格独立滚动，修复手机端文章横向溢出；旧项目正文重复标题不再与页头形成两个 H1。
- 搜索：原生模态框、键盘焦点约束、Esc / 快捷键操作、中文状态、异步请求取消及错误提示。
- 初始正文使用服务端可见状态，不依赖页面入场动画才显示。
